# v1.4.0：真题证据索引

发布日期：2026-08-29

本版本在不公开完整题面、答案或解析的前提下，为 2010—2026 数学一建立逐题证据元数据。17 卷 385 题全部挂接正式知识节点、一个主母题、至多两个辅助母题、100 分难度、短路线标签和衍生错因标签。

新增的四向索引支持从年份、母题、知识节点和错因反查题目。28 套 616 题模拟卷只进入匿名聚合统计，节点和母题分组不足 5 题时不发布。

2026 数据保持严格真实性边界：考后重构、多源交叉、答案经模型独立复算；非官方原卷、非官方答案，不代表人工确认。

机器接口位于 `data/exam-evidence/v1/`，包含版本化 Schema、确定性生成器、反向索引和带 SHA-256 的 manifest。个人训练数据仍只保存在被 Git 忽略的 `data/local/`。
