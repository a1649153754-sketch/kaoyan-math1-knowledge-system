# v1.5.0：全章节深度完善与冲刺版

发布日期：2026-08-30

本版本完成四份主题正文的全量内容审计：H0—H10、L0—L7、P1—P9、M1—M7 共 35 章、253 个正式节点全部补齐六字段执行卡，并配套 87 组“为什么成立—怎么用—小例题 / 路线演示—哪里会失效”的核心讲解。稳定节点与资源 ID 均未删除、重排或复用。

节点母题证据由 2010—2026 去题面化正式卷索引直接计算。每张卡同时给出题数、挂接分值与平均难度；当前没有逐题证据的 71 个节点明确标为零，不用虚构频次替代知识结构判断。外部来源只用于核验定理条件和延伸阅读，正文自身包含主要定义、原理、推导、例题与失效边界。

新增版本化冲刺选择清单与确定性生成器。节点达到“题数 ≥8、挂接分值 ≥40、跨章节题数 ≥6，或平均难度 ≥50 且题数 ≥4”中的任一条件即进入客观候选；本版据此生成 56 个候选节点，并从 212 张公式卡中抽取 64 张核心公式，完整汇入 21 组定理条件和 40 张反例卡。

CI 现在会自动发现全部章节，拒绝整章或节点卡缺失、标题错配、字段缺失、证据计数过期、零证据虚构、讲解过短、结构缺段、未知来源、非法冲刺选择和生成文件漂移。个人成绩、用时、错题与复测记录仍只保存在被 Git 忽略的 `data/local/`，不进入 Pages、bundle、Release 或 PR。

本目录只保存版本说明；本次不预先创建 GitHub Release，也不自动合并最终 Pull Request。
