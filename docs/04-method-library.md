### 核心讲解1：定义把模糊题意变成可以逐项验证的量词

**为什么成立**：极限、可导、可微、可积、收敛、独立和正定都不是形容词，而是带有“对任意”“存在”“充分接近”或“所有非零向量”等量词的陈述。回到定义能揭示必要信息：可微需要统一线性近似，独立需要任意事件分解，正定需要所有方向为正。许多反例正是满足弱定义却不满足强定义。

**怎么用**：读题先圈出对象和量词，把结论改写为定义格式。若要证明存在，找构造或定理；要证明唯一，假设两个对象再比较；要否定全称命题，只需一个满足前提的反例。定义计算困难时再寻找等价判据，但要记录等价成立的范围。

**小例题 / 路线演示**：判断二元函数在原点可微，不能只算两个偏导；要写 `f(h,k)-f(0,0)-f_xh-f_yk=o(√(h²+k²))`。若余项比值沿某条路径不趋零，就直接否定可微。定义明确告诉我们需要统一控制所有方向。

**哪里会失效**：把“可导推出连续”反过来使用，会被 `|x|` 在 0 的反例击破；把“不相关”当“独立”则忽略联合结构。若反例本身不满足题设前提，例如用非对称矩阵否定实对称矩阵正定判据，它并没有真正否定命题。

### 核心讲解2：条件清单是公式调用的接口契约

**为什么成立**：公式把一段定理证明压缩成可调用结果，而定理条件就是接口。洛必达需要未定式与可导邻域，Green/Gauss/Stokes 需要区域、方向和光滑性，t/χ²/F 需要正态与独立结构。漏条件时结果偶尔算对只是巧合，无法在变式中稳定复用。

**怎么用**：在草稿边缘固定写五类检查：对象与定义域、局部光滑性、全局区域/拓扑、方向与端点、参数与自由度。每调用一次定理就标条件来源；若有一项题设未给，决定是能从已有条件推出、需要分区补洞，还是应退回直接计算。

**小例题 / 路线演示**：看到闭合平面曲线积分，不是立刻写 Green。先问曲线是否正向、区域是否有孔、P,Q 在整个区域邻域是否连续可偏导、内部是否有奇点。若原点是奇点，就挖去小圆并处理内边界，而不是把偏导相等当成路径无关。

**哪里会失效**：结果合法性检查不能只看代数：概率必须在 `[0,1]`，方差非负，秩不超尺寸，几何面积非负，通量方向与法向一致。若终值越界，优先回查条件、符号、上下限和自由度，而不是通过取绝对值等手段修饰答案。

### 章末路线选择

1. 先把概念展开为带量词的定义。
2. 把定理条件按对象、局部、全局、方向、参数分类核对。
3. 缺条件时补证、分区或换直接路线，不强套公式。
4. 结果用范围、维数、方向与量纲作最后合法性检查。

### 达标标准

- 能用原始定义解释关键概念的强弱关系。
- 能在公式调用前完整列出条件而不是事后补写。
- 能根据缺失条件主动换路并说明原因。

### 核心讲解1：对称性是变换下的不变量或变号量

**为什么成立**：对称不是“图看起来漂亮”，而是存在一个保持求和/积分区域的变换 T。若权重在 T 下不变而被积函数变号，点与 T 点贡献抵消；若被积函数不变，贡献相同；若变量轮换保持整体结构，就能推出多个积分或分布量相等。这一原则横跨一元积分、重积分和联合分布。

**怎么用**：先明确变换，例如 `x→-x`、`x→a+b-x`、`x↔y` 或空间反射。分别写区域是否不变、Jacobian 绝对值、密度和被积函数变化。只有全部通过，才使用判零、倍增或轮换。定积分区间中心不是零时，先平移或用 `a+b-x`。

**小例题 / 路线演示**：在交换对称区域 D 上，若 `f(x,y)=f(y,x)`，则 `∬_D x f(x,y)dA=∬_D y f(x,y)dA`，因为换元 `x↔y` 保持 D 和微元。相加后可把 `∬(x+y)f` 化为两倍其中一项。

**哪里会失效**：单位圆区域对称，但密度 `1+x` 破坏 x 反射不变，因此 `∬x(1+x)dA` 不为零。概率中联合密度交换对称只说明 X、Y 同分布，不说明独立。对称性每次都要检查完整权重。

### 核心讲解2：带方向对象的对称要同步变换定向

**为什么成立**：第二类曲线与曲面积分积累向量场对有向切向或法向的分量。几何反射不仅改变坐标，还可能反转曲线方向、法向或某些场分量，所以标量奇偶规则不能原样搬来。对称矩阵的谱结构则是另一种不变性：正交基变换保持内积，使不同特征方向可以正交分解。

**怎么用**：对曲线曲面积分画出变换前后箭头，逐个替换场分量和微分形式；必要时用向量点积表达，减少符号遗漏。矩阵问题先确认实对称，再利用正交变换保持长度和角度，将问题分解到互相正交的特征子空间。

**小例题 / 路线演示**：一条闭曲线关于 x 轴对称，反射会把上半段的行进方向映到下半段但可能与指定正向相反。比较 `Pdx+Qdy` 时，y、dy 与方向都要同步变换；仅把 y 换成 -y 而保留 dy 和路径次序，会得到错误符号。

**哪里会失效**：第一类积分无方向，不代表第二类也无方向。变量轮换时向量场的分量必须随坐标置换，不能只交换 x、y。一般矩阵即使元素呈某种对称图案，也不必满足实对称谱定理，条件是严格的 `Aᵀ=A`。

### 章末路线选择

1. 写出具体对称变换而不是只说“由对称性”。
2. 逐项检查区域、权重、微元和方向。
3. 变号量用于抵消，不变量用于倍增，轮换用于建立相等式。
4. 向量与矩阵对象优先用点积、法向和正交变换表述。

### 达标标准

- 能把一元、重积分和概率对称写成变量变换。
- 能发现密度或附加权重对几何对称的破坏。
- 能正确处理第二类积分中的方向同步。

- **温柔讲解**：如果你在 `M3.3` 的“参数可能改变对象定义域，分类前先写参数空间”这里卡住，先别责怪自己，它本来就同时牵着几层信息。把它放回把参数当成改变结构的开关，核心任务只是弄清“参数可能改变对象定义域，分类前先写参数空间”。先问“参数变化时哪一个零点、边界或秩会先发生改变？”，再用“收集分母为零、判别式为零、秩下降、Hessian 退化、端点收敛和定义域变化等临界方程，在开区间取样并逐个回验临界点”把大问题拆成小步骤。一旦碰到“在含参因子非零的分支做出的约分或除法不能延伸到临界点；一般情形结论也不能用连续直觉替代临界值的重新计算”，就回到条件清单重新对齐，而不是硬算到底。等你能解释为什么选这条路、又为什么在边界处停下，这个节点就不再只是记忆，而会变成你的判断力。

### 核心讲解1：参数分类的本质是寻找结构不再稳定的点

**为什么成立**：在参数连续变化而关键分母、主元、判别式或收敛指数不穿过零时，根数、秩、符号和收敛类型通常保持稳定。结论只会在定义域边界、根合并、主元消失、Hessian 退化或级数端点等位置改变。先找这些临界值，就把无限参数问题压缩成有限分支。

**怎么用**：先列参数空间，再从每个会被除、开方、取对数或作为主元的表达式提取零点；补充判别式、边界相交、特征根重合和收敛指数临界。排序后在开区间取代表值判断，最后把每个临界值代回原题，而不是代回已约分的式子。

**小例题 / 路线演示**：系统 `x+ay=1, ax+y=1` 的临界值来自 `detA=1-a²=0`，即 `a=±1`。一般区间均唯一解；代回 a=1 得同一方程、无穷多解，a=-1 得矛盾、无解。两个临界点结构不同，不能合并处理。

**哪里会失效**：若先除以 `a-1`，a=1 分支会永久丢失。只看判别式为零也可能漏定义域边界，例如对数真数或概率参数空间。临界值清单应取并集，而不是只选最显眼的一项。

### 核心讲解2：开区间取样与临界点单验形成完整分类闭环

**为什么成立**：临界值把参数轴切成若干连通开区间；只要期间没有结构改变，选一个代表值即可判断整个区间。临界点本身常因重根、降阶、秩下降或等号出现而具有不同结论，所以必须独立计算。完整答案还要检查各分支并集覆盖参数空间且彼此不重叠。

**怎么用**：建立表格列“参数区间—关键符号/秩—结论—临界点回验”。每个开区间选算术最简单的值；边界使用原定义或原矩阵。最后检查端点是否该用开闭括号、等号条件是否能取到，以及题目所求是存在、唯一还是范围。

**小例题 / 路线演示**：反常积分 `∫₁^∞x^{-p}dx` 只有临界 p=1。取 p=2 得收敛，代表 `(1,∞)`；取 p=0 得发散，代表 `(-∞,1)`；p=1 单验为调和型发散。因此收敛域是严格的 `p>1`。

**哪里会失效**：用 p=0 的结论顺带覆盖 p=1 会漏掉临界结构；虽然两者在此都发散，其他题中临界点可能单独成立。分类表若漏参数原始范围，可能报告不存在的负方差、非法概率或对数参数。

### 章末路线选择

1. 先写参数空间，再收集所有结构变化候选。
2. 临界值排序，在每个开区间取简单代表值。
3. 所有临界点回到原式或原矩阵单独计算。
4. 检查分支互斥、完备及端点开闭。

### 核心讲解1：存在与唯一必须用两条独立逻辑链证明

**为什么成立**：连续函数端点异号给至少一个零点，单调性或 Rolle 反证给至多一个；方程组增广秩相等给相容，满列秩消除自由度给唯一；微分方程局部存在唯一也分别依赖连续与 Lipschitz 型条件。存在回答对象能否找到，唯一回答能否有第二个，二者量词不同。

**怎么用**：把目标拆成“至少一个”和“任意两个必相同”。存在段选构造、介值、紧致最值或相容性；唯一段假设两个解，作差、用单调或把差送入零空间。最后说明两段共同推出恰好一个，并标明作用区间。

**小例题 / 路线演示**：方程 `x³+x-1=0` 在 `[0,1]` 上端点异号且连续，故存在根；导数 `3x²+1>0`，函数严格递增，故至多一根。若只写导数正，只能说明最多一个，仍需端点信息保证真的有根。

**哪里会失效**：介值定理不保证唯一，单调性不保证目标值一定在值域内。线性方程 `Ax=b` 的 `r(A)=n` 对方阵可给唯一，但若系统不相容仍无解，因此必须先比增广秩。结论的定义域若分成多段，每段唯一不等于全域唯一。

### 核心讲解2：不同学科的存在唯一都可化成核空间或可逆性

**为什么成立**：线性问题中两个解之差落入齐次零空间，所以零空间平凡带来唯一；势函数若存在，其梯度给定，两个势函数之差在连通域上为常数；正定二次型只有零向量能取零，常用于唯一极小。共同模式是：先找一个对象，再证明任何两个对象的差只能是允许的平凡自由度。

**怎么用**：遇唯一性先写两个候选的差。线代让差进入 `N(A)`，微分方程让差满足齐次方程，原函数让差的导数为零，概率估计则比较目标函数是否严格凸。存在性另外通过构造、积分、相容判据或连续性完成。

**小例题 / 路线演示**：若 F、G 都是连续函数 f 在区间上的原函数，则 `(F-G)′=0`，由中值定理知 F-G 为常数。因此原函数族的唯一性是“模一个常数”的唯一；初值再把这个自由常数确定，得到唯一特解。

**哪里会失效**：定义域不连通时，每个连通分支可有不同常数，不能说全域只差一个常数。偏导条件给局部势场时，穿孔区域可能存在非零环流，阻碍全局势函数。所谓唯一必须明确允许哪些等价自由度。

### 章末路线选择

1. 先辨至少存在、至多一个、恰好一个或模某自由度唯一。
2. 存在用构造、介值、紧致或秩相容。
3. 唯一让两个候选作差，再用单调、零空间或正定性。
4. 检查结论是局部、每个连通分支还是全局。

### 核心讲解1：好变换让复杂对象变标准，同时补偿局部尺度

**为什么成立**：换元的目标是把曲线、区域、方程或分布变成更简单的标准对象。微积分中的导数/Jacobian 记录局部长度、面积和体积如何缩放；概率密度变换用相同补偿保证总概率仍为 1；微分方程代换则把非线性结构变成线性或可分离结构。映射若非一一，多个原像贡献必须合并。

**怎么用**：先列新变量、逆映射和新定义域，再计算一维导数或多维 Jacobian。积分同时替换被积函数、微元和上下限；概率同时替换支持和密度；微分方程同时替换未知函数及导数。完成后用总面积、总概率或代回原方程复核。

**小例题 / 路线演示**：极坐标把圆盘变为矩形参数域，但 `dA` 必须变成 `rdrdθ`；随机变量 `Y=X²` 则有两个原像 `±√y`，密度贡献相加。两例都说明变换不仅换符号，还要记录映射的尺度和分支。

**哪里会失效**：只换区域不换 Jacobian会改变总量，只换公式不改上下限会混用变量。Jacobian 为零处映射可能折叠，不可直接使用一一换元。平方代换、绝对值和极坐标负半径尤其容易产生多重覆盖。

### 核心讲解2：降维与矩阵变换要先决定保留什么

**为什么成立**：Green、Stokes、Gauss 在边界与内部之间改变积分维数，但保留的是带方向的环流或通量；线代中初等变换保秩与方程等价，相似保线性变换的谱，合同保二次型惯性。所谓简化只有在目标性质被保留时才有意义，否则计算更短却回答了另一个问题。

**怎么用**：先写目标不变量。曲线曲面积分选择维数转换时检查边界、方向与奇点；矩阵题按求解、谱、二次型分别选初等、相似、合同。降维后保留补面、边界段或自由变量，最终把结果翻译回原对象。

**小例题 / 路线演示**：计算复杂闭曲面上向量场通量，若散度简单，可用 Gauss 转成体积分；但开曲面必须先补面并扣除补面通量。线代中求 A 的特征值不能先任意行化简，因为行变换虽简化元素却不保谱。

**哪里会失效**：变换后的标准形若不能逆回原变量，只能说明像空间上的问题。相似与合同形式接近但不变量不同。使用积分定理穿过奇点或忘记方向，相当于在降维过程中丢掉了源项或符号。

### 核心讲解1：辅助函数来自把目标倒推成导数或端点差

**为什么成立**：中值定理把端点增量与区间内某点导数连接。构造辅助函数不是猜魔法式，而是先把目标整理成 `F′(ξ)=0`、某个导数比或两个端点值相同，再积分或反向识别 F。差函数法同样把不等式转成函数符号，借单调、极值或凸性控制。

**怎么用**：从结论中的 `f(ξ),f′(ξ)` 反推可能的导数结构；端点相同用 Rolle，单个增量用 Lagrange，两个增量比用 Cauchy。证明不等式令 `F=左-右`，寻找易控制的基点值，再研究 F′ 或 F″。写出连续、可导与 ξ 区间。

**小例题 / 路线演示**：证明 `ln x≤x-1 (x>0)`，令 `F=x-1-ln x`。有 `F′=1-1/x`，在 `(0,1)` 负、`(1,∞)` 正，所以 x=1 为全局最小且 F(1)=0。等号条件也随最小点自动得到。

**哪里会失效**：若只写“显然构造 F”，读者无法验证路线。中值定理条件缺闭区间连续或开区间可导时不能套。差函数导数符号若仍比原不等式更难，就没有完成降复杂度，应改用凸性、积分或 Taylor。

### 核心讲解2：唯一性、线代证明和定义证明都依赖结构化改写

**为什么成立**：根数上界可假设根过多，再用 Rolle 逐次制造更多导数零点；线代结论常由像/核包含和维数公式推出；概率中的无偏、独立则直接展开定义。共同方法是把抽象结论翻译成一个更基础、能逐项核验的结构，而不是堆公式。

**怎么用**：唯一性令两个候选作差；根数上界画出 Rolle 迭代次数；线代先写 `Im`、`Ker` 或行空间包含，再取维数；概率定义证明写联合概率/密度分解或期望求和。每一步注明使用方向，尤其区分必要和充分。

**小例题 / 路线演示**：若 n 次多项式有超过 n 个不同实根，反复使用 Rolle 后其 n 阶导数应至少有一个零点，但 n 阶导数是非零常数，矛盾。证明没有求出任何根，却用次数结构给出根数上界。

**哪里会失效**：Rolle 只能在相邻不同根之间制造点，重复根和端点要谨慎计数。线代只比较秩可能不足以证明空间相同，还需包含关系。定义展开若交换无穷和、积分或期望，要确保收敛和可积条件。

4. 否定命题从最低维常用对象寻找满足全部前提的反例。

### 核心讲解1：中间量命名把认知负担转成可复核结构

**为什么成立**：长表达式反复抄写会增加负号、上下限和指标错误。把参数积分、特征多项式、联合区域或标准化统计量命名后，可以分别检查其定义、范围和变换，主线只保留关系。好的命名不是多写字，而是让每个采分点成为可独立验证的小模块。

**怎么用**：首次出现写 `令…` 并给完整定义；后续只用同一符号，不临时改变量。积分换元保持一种变量，矩阵标尺寸，概率统计量标 H0 下分布和自由度。每个大步骤结束后用一行说明条件或结论，不把关键逻辑藏在连续等号里。

**小例题 / 路线演示**：参数积分先令 `I(a)=∫…dx`，求导时明确积分变量与参数不同；线代高次幂令特征多项式 `p(λ)`；二维概率把支持域记作 D。这样后续的换元、求导和边界检查都有固定对象，减少重复抄写。

**哪里会失效**：同一个字母同时表示积分上限、随机变量和参数，会让合法求导变得不可判断。换元后新变量却保留旧上下限、矩阵乘积省略括号、F 分布自由度不写顺序，都是表面简洁却丢失数学信息。

### 核心讲解2：结果自检与采分点让错误在提交前暴露

**为什么成立**：数学结果受到许多无需重算的硬约束：概率在 `[0,1]`，方差非负，秩不超过尺寸，面积体积非负，密度积分为 1，物理量有正确单位，特征值和积与行列式相符。利用这些不变量能快速发现局部错误。规范书写则让定理名称、关键等式和条件成为明确采分点。

**怎么用**：计算前估计符号、范围和数量级，计算后逐项核对。证明题写定理名称与条件，积分题写区域/方向，统计题写模型和自由度，线代题写秩判断。若检查失败，按“模型—条件—方向—代数”逆序定位，不通过取绝对值等修补结果。

**小例题 / 路线演示**：算得某概率为 1.2，应先查支持区与归一化；算得方差 -0.3，回查二阶矩与协方差符号；求 3×5 矩阵秩为 4 虽可能，若为 6 则立即不合法。自检利用结构上界，不必重做全题。

**哪里会失效**：量纲和范围正确只是必要条件，不保证推导正确；两个错误可能互相抵消。因此自检用于发现错误，不能代替条件证明。答题模板若只写结论不写关键等式，仍会丢采分点；反过来堆满无关公式也会遮蔽主线。
