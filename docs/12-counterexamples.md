# 第十二部分 反例与失效边界库（v1.2 新增）

真正拉开分差的往往不是“公式不会”，而是把只在特定条件下成立的结论当成普遍真理。本部分把高频错误命题压缩为最小反例。做选择题时，优先尝试用这些反例快速否定。

## 12.1 高等数学反例卡（B-H）

| 边界 ID | 错误命题 | 正确版本 | 最小反例 / 失效原因 |
| --- | --- | --- | --- |
| B-H01 | 有界数列一定收敛 | 单调且有界才可由单调有界准则推出收敛 | (-1)^n 有界但不收敛 |
| B-H02 | 在和差中可任意使用等价无穷小 | 等价替换对乘除最稳；相消时应 Taylor 或保留高阶 | sin x-x 的主项若都换成 x 会错误得到 0 |
| B-H03 | 函数连续就一定可导 | 可导⇒连续，逆命题不成立 | f(x)=\|x\| 在 0 连续但不可导 |
| B-H04 | f′(x₀)=0 就是极值点 | 驻点只是候选，要看导数变号或高阶结构 | f(x)=x³ 在 0 无极值 |
| B-H05 | f″(x₀)=0 就是拐点 | 还需函数在点附近凹凸性发生变化 | f(x)=x⁴ 在 0 的二阶导为 0，但无凹凸变化 |
| B-H06 | 函数有原函数就一定能写成初等函数 | 原函数存在与能否用初等函数表示是两回事 | e^{-x²} 连续有原函数，但无初等闭式 |
| B-H07 | 反常积分被积函数趋于 0 就收敛 | 趋零只是必要性直觉，仍需比较/判别 | ∫_1^∞ dx/x 发散 |
| B-H08 | 二重极限沿几条路径相同即可判存在 | 有限路径只能用于否定；证明需统一估计 | 可构造沿所有直线同极限、沿曲线路径不同的函数 |
| B-H09 | 二元偏导都存在就可微 | 需增量线性主部与余项 o(ρ) | f=xy/√(x²+y²)（原点定义 0）偏导存在但不可微 |
| B-H10 | Hessian 判别式 D=0 就一定没有极值 | D=0 只是二阶判别失效，需要高阶/路径分析 | f=x⁴+y⁴ 在原点有极小值 |
| B-H11 | P_y=Q_x 就一定路径无关 | 还需区域适当单连通且场光滑 | (-y/(x²+y²))dx+(x/(x²+y²))dy 在穿孔平面偏导相等但绕原点积分非零 |
| B-H12 | 级数一般项趋 0 就收敛 | a_n→0 只是必要条件 | 调和级数 Σ1/n 发散 |
| B-H13 | 幂级数端点自动继承内部收敛性 | 半径内绝对收敛，端点必须分别判定 | Σx^n/n 在 x=1 与 x=-1 性质不同 |
| B-H14 | 第二类曲线/曲面积分可只轮换 x,y,z | 还要同步变换场分量、微分形式和方向 | 方向反转会使第二类积分变号 |

## 12.2 线性代数反例卡（B-L）

| 边界 ID | 错误命题 | 正确版本 | 最小反例 / 失效原因 |
| --- | --- | --- | --- |
| B-L01 | AB=0 ⇒ A=0 或 B=0 | 矩阵有零因子，除非附加可逆等强条件 | 取非零投影矩阵 A=diag(1,0), B=diag(0,1) |
| B-L02 | r(A+B)=r(A)+r(B) | 只能保证 r(A+B)≤r(A)+r(B) | B=-A≠0 时左边为 0 |
| B-L03 | 初等行变换保持特征值 | 初等行变换保持秩；相似变换才保持特征结构 | 交换单位矩阵两行得到交换矩阵，特征值已改变 |
| B-L04 | 特征多项式相同就相似 | 相似⇒特征多项式相同，逆命题一般不成立 | 零矩阵与非零二阶幂零矩阵特征多项式同为 λ²但不相似 |
| B-L05 | 有重特征值就不可对角化 | 要比较几何重数与代数重数 | 单位矩阵只有一个重特征值但可对角化 |
| B-L06 | 秩相同的齐次方程组一定同解 | 同解要求零空间相同/行空间相同 | [1,0]x=0 与 [0,1]x=0 均秩 1，但解集不同 |
| B-L07 | 非齐次系统 r(A)=r(A\|b) 就有唯一解 | 还需共同秩等于未知量个数 n | 一个方程两个未知量且相容，通常有无穷多解 |
| B-L08 | 两个非齐次系统秩相同就同解 | 需完整解集一致：公共特解+相同零空间 | x=0 与 x=1 的系数矩阵秩相同但解集不同 |
| B-L09 | 两个非齐次解之和仍是原方程解 | 解之差是齐次解；特解+齐次解仍是特解 | Ax=b 时 A(x₁+x₂)=2b |
| B-L10 | 实矩阵特征值全为正就一定正定 | 二次型正定判据针对实对称矩阵 | A=[[1,3],[0,1]] 的特征值均为 1，但 xᵀAx=x₁²+3x₁x₂+x₂² 不定 |
| B-L11 | detA>0 就能推出 A 正定 | 正定需全部特征值正或全部顺序主子式正 | diag(-1,-1) 行列式为 1 但负定 |
| B-L12 | 相似与合同是同一种变换 | 相似保持特征结构，合同保持二次型惯性 | 变换形式分别为 P^{-1}AP 与 CᵀAC |

## 12.3 概率统计反例卡（B-P）

| 边界 ID | 错误命题 | 正确版本 | 最小反例 / 失效原因 |
| --- | --- | --- | --- |
| B-P01 | 互斥事件一定独立 | 若两事件概率都正，互斥反而不独立 | AB=∅ 给 P(AB)=0，但 P(A)P(B)>0 |
| B-P02 | 两两独立一定相互独立 | 相互独立要求任意子组交概率可分解 | 两次抛硬币令 A=首正、B=次正、C=两次同面，可两两独立但不相互独立 |
| B-P03 | 不相关一定独立 | 一般只知 Cov=0；联合正态时才可反推独立 | X~对称分布，Y=X²，常有 Cov(X,Y)=0 但显然相关 |
| B-P04 | 概率密度必须不超过 1 | 密度只需非负且总积分为 1 | U(0,1/2) 的密度为 2 |
| B-P05 | 分布函数处处可导且导数就是密度 | 绝对连续分布才有密度，且 F′=f 只在可导处/几乎处处 | 离散分布函数有跳跃 |
| B-P06 | 同分布的随机变量一定独立 | 同分布只描述边缘，不描述联合关系 | 令 Y=X，则 X,Y 同分布但通常不独立 |
| B-P07 | 两个正态变量之和一定正态 | 独立正态或联合正态线性组合才保证正态 | X~N(0,1)，U 独立且等概率取±1，令 Y=UX；Y 仍正态，但 X+Y 有一半概率等于 0，不是正态 |
| B-P08 | 独立随机变量方差相加，所以任何时候 D(X+Y)=DX+DY | 一般还需加 2Cov(X,Y) | 取 Y=X，则 D(X+Y)=4DX |
| B-P09 | 中心极限定理说明样本均值有限样本严格正态 | CLT 给 n 大时的近似；正态总体才有精确正态 | 非正态总体的小样本均值通常非正态 |
| B-P10 | 用 1/n 定义的样本方差对 σ² 无偏 | 无偏样本方差分母为 n-1 | E[(1/n)Σ(X_i-X̄)²]=(n-1)σ²/n |
| B-P11 | 不拒绝 H₀ 就证明 H₀ 正确 | 只能说证据不足以拒绝 H₀ | 低功效/小样本下假 H₀ 也可能未被拒绝 |
| B-P12 | p 值是 H₀ 为真的概率 | p 值是在 H₀ 成立时观察到当前或更极端数据的概率 | 频率学派检验没有直接给 P(H₀\|data) |
| B-P13 | 无偏估计量一定最好 | 无偏只是一个性质，还需比较方差、均方误差和一致性 | 有偏但方差显著更小的估计量可能 MSE 更小 |
| B-P14 | 置信度 95% 表示本次算出的固定区间有 95% 概率包含参数 | 频率解释是重复抽样构造的区间有 95% 覆盖率 | 区间算出后参数与区间均视为固定 |
