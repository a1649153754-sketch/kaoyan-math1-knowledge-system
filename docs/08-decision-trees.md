# 第八部分 高频题型决策树（v1.1 新增）

决策树不是固定模板，而是“先判断什么、再选什么”的顺序。每做完一类题，把自己的替代路线和失败案例补到对应树下。

## 8.1 极限计算决策树

1. 先代入并识别类型：正常值、0/0、∞/∞、0·∞、∞-∞、1^∞、0^0、∞^0。
2. 代数结构明显：优先因式分解、有理化、通分或换元。
3. 局部小量乘除：优先等价无穷小；发生相消：改用 Taylor。
4. 指数幂型：先取对数，把幂型转成乘积型极限。
5. 有明显单调递推：走“猜极限—有界—单调—唯一性”。
6. 洛必达条件满足且能明显降复杂度才用；一次后更复杂就换方法。
7. 最后检查左右极限、参数临界值和展开阶数。

## 8.2 中值定理证明决策树

1. 把结论整理成“某个 ξ 处某表达式等于 0”或“两个增量之比”。
2. 端点值相同或可造相同：优先 Rolle。
3. 出现 f(b)-f(a)：优先 Lagrange。
4. 出现两个函数增量之比：优先 Cauchy。
5. 目标含 ξ、f(ξ)、f′(ξ)：从目标反推辅助函数的导数。
6. 需要多个中值点时分区间分别使用，再用代数关系连接。
7. 写完整连续、可导、端点条件和 ξ 所在区间。

## 8.3 一元积分决策树

1. 先分类：有理式、根式、三角式、指数对数、复合结构、乘积结构。
2. 内函数导数齐全：凑微分；根式标准型：三角/变量代换。
3. 乘积中一部分求导后变简单：分部积分。
4. 有理函数：先除法再部分分式；三角有理式：半角或奇偶拆分。
5. 定积分先看对称、周期、区间映射，再决定是否直接算。
6. 反常积分先拆瑕点、写极限，再判敛与求值。
7. 换元后同时检查变量、微分、上下限和方向。

## 8.4 多元极值决策树

1. 先判断区域：开区域、闭区域还是带约束。
2. 开区域内部：解梯度为零，使用 Hessian；退化时换高阶或路径。
3. 等式约束：Lagrange 乘数，同时检查约束梯度异常点。
4. 闭区域：内部驻点 + 每段边界降维 + 角点全部比较。
5. 参数题：找驻点合并、Hessian 判别式为零和边界穿越。
6. 若目标或约束有明显对称性，先降维或猜等号点，再严格验证。
7. 最终比较函数值，而不是只判断局部类型。

## 8.5 重积分决策树

1. 画区域并标交点、上下表面和投影。
2. 比较直角、极、柱、球或一般换元对“区域 + 被积函数”的总简化程度。
3. 写积分限前确定切片方向；非单值边界立即分区。
4. 先查奇偶、轴对称、原点对称和变量轮换。
5. 换元时同步变换区域、被积函数、Jacobian。
6. 三重积分选择先一后二或先二后一，以最简单边界为准。
7. 结果用正负、量纲、粗界和对称性复核。

## 8.6 曲线曲面积分决策树

1. 先判四类中的哪一类：第一类无方向，第二类有方向。
2. 能否用 Green/Gauss/Stokes 把难积分转为简单区域、体积或曲面。
3. 检查定理条件：闭合、光滑、单连通、连续偏导、是否含奇点。
4. 开曲面考虑补面；非单连通区域考虑挖洞；同边界曲面可替换。
5. 方向先画：边界正向、曲面外侧/上侧、右手规则。
6. 对称性必须连同向量场分量和方向一起变换。
7. 若定理法不合法，回到参数化直接计算。

## 8.7 线性方程组决策树

1. 写尺寸和三个数：未知量 n、r(A)、r(A|b)。
2. 先判无解/唯一/无穷多，再求具体解。
3. 参数值可能为零的行不要直接除，先保留因子并找秩变化点。
4. 齐次同解比较零空间/行空间；非齐次同解比较增广最简形或公共特解 + 同一零空间。
5. 公共解把方程纵向合并；解集包含转为约束的线性表示。
6. 由解反推时用“特解 + 零空间”和解之差。
7. 最后核对自由变量数与 n-r 一致。

## 8.8 特征值与二次型决策树

1. 先用迹、行列式、秩、三角结构和已知特征向量减少计算。
2. 求每个特征值的特征子空间，重根必须检查维数。
3. 问可对角化：统计独立特征向量总数；实对称矩阵直接正交对角化。
4. 问 A^n：优先对角化或利用低阶多项式关系降次。
5. 问二次型：先写对称矩阵，决定使用配方、合同或正交变换。
6. 问正定：实对称前提下选特征值或顺序主子式。
7. 区分 AP=PΛ、P^{-1}AP=Λ 与 C^TAC，避免相似和合同混淆。

## 8.9 概率分布题决策树

1. 先判断离散、连续还是混合，并画支持集。
2. 目标是概率：直接在支持集上求和/积分；目标是分布：优先事件法。
3. 一维变换用分布函数法最稳；单调时再用密度公式。
4. 二维变换画原像区域、求逆和 Jacobian；多对一要分支相加。
5. 和用卷积，最大最小用分布函数，次序统计量用计数结构。
6. 独立性同时看分解公式和支撑区域。
7. 结果检查归一化、非负和概率范围。

## 8.10 统计推断决策树

1. 先写总体分布、参数、样本量与未知量。
2. 点估计：矩估计看矩方程，MLE 看似然与参数边界。
3. 区间/检验：先选枢轴量 Z、t、χ² 或 F。
4. 均值问题先辨 σ 已知/未知；两总体还要辨独立性和方差关系。
5. 方差问题用 χ² 或 F，并检查自由度与分子分母。
6. 单侧/双侧由备择假设决定尾部，不能由样本结果临时改变。
7. 结论回到题目语境，并区分“不拒绝”与“证明为真”。

## 8.11 五个高频易混专题

### 换元：新元=f(旧元) 与 旧元=f(新元)

- 两种写法本质等价。关键不是谁写在左边，而是把变量、微分、积分限和可逆区间同时转换。
- 一元有向定积分用 φ′(t) 与端点顺序体现方向；多重积分的面积/体积换元使用 Jacobian 绝对值。
### 对称二阶差商与导数定义

- [f(x+h)+f(x-h)-2f(x)]/h² 是二阶局部信息；二阶可微时极限为 f″(x)。仅凭一阶导数定义不能直接推出。
### 非齐次方程组是否存在同解概念

- 存在。比较的是完整解集。最稳判据是增广矩阵最简形相同；也可验证有公共特解且对应齐次方程零空间相同。
### 次序统计量最大值与最小值

- 最大值事件“全部不超过 x”，最小值事件“至少一个小于等于 x”的对立；先写分布函数通常最稳。
### 二型曲线/曲面积分的轮换对称性

- 不能只把 x,y,z 轮换。必须确认区域、向量场分量、微分形式和方向在同一变换下整体不变或按确定符号变化。
