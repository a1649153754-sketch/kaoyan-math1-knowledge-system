## 9.2 单节点知识卡

| 字段 | 填写内容 |
| --- | --- |
| 节点编号 | 例：H8.7 Gauss 公式 |
| 概念/对象 | 这条知识在研究什么对象？ |
| 使用条件 | 所有前提逐条写出，尤其是区间、光滑性、可逆性、独立性。 |
| 标准结论 | 公式、定理或结构结论。 |
| 触发词 | 题目出现什么结构时应想到它？ |
| 典型路线 | 主方法 + 一条替代方法。 |
| 易错边界 | 一个反例或不适用情形。 |
| 掌握证据 | 题号、正确率、用时、能否口述。 |
| 下次回测 | 3 天 / 7 天 / 14 天的具体日期。 |
