# 第五部分 维护模板与复习闭环

## 5.1 单节点更新模板
- 节点编号：例如 H2.4
- 当前状态：0/1/2/3/4
- 新增内容：概念 / 定理 / 题型 / 方法 / 易错点 / 例题索引 / 错题索引
- 证据：最近一次真题或限时训练的正确率与用时
- 下一步：一个可执行动作，例如‘完成 10 道中值定理构造题并总结辅助函数来源’

## 5.2 错题归因标签
- C 概念错误：定义、条件或对象理解错误。
- T 定理错误：定理条件漏检、结论方向记反。
- M 方法错误：没有识别题型或选错路线。
- A 运算错误：符号、代数、积分上下限、矩阵顺序。
- R 阅读错误：条件漏看、问法看错、范围抄错。
- S 速度问题：方法正确但步骤过长或熟练度不足。
- E 表达问题：解答题缺关键依据、证明不闭合。

## 5.3 每周闭环
- 周初：从状态 1—2 的 A+/A 节点中选 3—5 个作为本周主攻。
- 训练：基础题验证概念，综合题验证连接，真题验证命题表达。
- 复盘：每道错题只归一个主因、一个次因，并挂到具体节点。
- 周末：将能连续正确完成且可口述方法的节点升级一级；仅看懂答案不升级。
- 回测：对升级节点隔 3 天、7 天、14 天各抽一道题。

本地数据已经初始化后，可用以下命令自动生成对应视图：

```bash
python scripts/validate_local_data.py
python scripts/generate_local_reports.py
```

输出位于被 Git 忽略的 `data/local/reports/`，只用于个人复盘。

## 5.4 阶段验收
- 基础阶段：所有 A+/A 节点至少达到 2 级；定义和公式无明显空白。
- 强化阶段：核心节点达到 3 级；能完成跨章节综合题并建立错题索引。
- 真题阶段：按年份限时；记录知识节点、用时、失分原因和替代路线。
- 冲刺阶段：只修复高价值薄弱点，保持计算手感和答题节奏，不再无边界扩张资料。
