# 第七部分 核心定理条件索引（v1.1 新增）

这一部分不追求重复课本证明，而是把“什么时候能用、能推出什么、最常错在哪里”压缩成条件卡。做题时先检查条件，再写定理名称。

## 7.1 夹逼准则

- 条件与结论：若在某去心邻域或充分大 n 后有 g≤f≤h，且 g、h 趋于同一极限 A，则 f→A。
- 易错边界：上下界必须在同一趋近过程成立；只知道函数有界不能推出极限存在。
## 7.2 单调有界准则

- 条件与结论：单调递增且有上界的数列收敛；单调递减且有下界的数列收敛。
- 易错边界：先证单调再证相应方向的有界；“有界”单独不够。
## 7.3 洛必达法则

- 条件与结论：0/0 或 ∞/∞ 型；去心邻域可导；分母导数不为零；导数商极限存在或为无穷。
- 易错边界：非未定式、离散数列、反复循环时不能机械使用。
## 7.4 闭区间连续函数性质

- 条件与结论：f 在 [a,b] 连续，则有界且取得最大最小值，并具有介值性质；若端点异号则至少有零点。
- 易错边界：“取得最值”依赖闭区间；零点定理只保证存在，不保证唯一。
## 7.5 Rolle / Lagrange / Cauchy 中值定理

- 条件与结论：闭区间连续、开区间可导；Rolle 另需端点值相等，Cauchy 对两个函数并需分母增量适当非零。
- 易错边界：区间条件和可导条件必须写；中值点 ξ 只保证存在，不等于中点。
## 7.6 Taylor 公式

- 条件与结论：函数在展开点附近具相应阶导数；Peano 余项用于局部阶，Lagrange 余项还要求更强的邻域可导条件。
- 易错边界：展开阶数由相消决定；写出余项类型，不能把有限项展开当恒等式。
## 7.7 微积分基本定理

- 条件与结论：f 连续时，F(x)=∫_a^x f(t)dt 可导且 F′(x)=f(x)；若 F 是 f 的原函数，则定积分等于端点差。
- 易错边界：反常积分或被积函数不连续时先处理定义，不能直接套 Newton-Leibniz。
## 7.8 隐函数存在与求导

- 条件与结论：方程 F(x,y)=0 在点附近满足 F 连续可微且 F_y≠0，可局部确定 y=y(x)，并有 y′=-F_x/F_y。
- 易错边界：只在局部成立；分母偏导为零时该公式不能直接用。
## 7.9 Green 公式

- 条件与结论：平面区域及分片光滑边界满足条件，P,Q 有连续偏导，边界按正向取向。
- 易错边界：有孔区域内边界方向相反；区域含奇点时需挖洞或直接算。
## 7.10 Gauss 公式

- 条件与结论：封闭分片光滑曲面取外侧，向量场在所围区域内具连续偏导。
- 易错边界：开曲面先补面；奇点在体内时不能直接套。
## 7.11 Stokes 公式

- 条件与结论：定向分片光滑曲面与其边界方向满足右手规则，向量场在邻域内具连续偏导。
- 易错边界：换曲面可以，但边界和方向必须保持一致。
## 7.12 幂级数逐项运算

- 条件与结论：在收敛区间内部，幂级数可逐项求导和积分，所得幂级数收敛半径不变。
- 易错边界：端点必须重新判定；区间外不能使用由和函数得到的等式。
## 7.13 秩—零空间定理

- 条件与结论：A 为 m×n 矩阵，则 dim N(A)+r(A)=n。
- 易错边界：n 是未知量/列数，不是行数；基础解系向量数为 n-r。
## 7.14 Rouché-Capelli 判定

- 条件与结论：Ax=b 有解当且仅当 r(A)=r(A|b)；若该共同秩等于 n 则唯一，否则无穷多。
- 易错边界：比较的是系数秩和增广秩；非齐次方程不能只看 r(A)。
## 7.15 可对角化判据

- 条件与结论：n 阶矩阵可对角化当且仅当有 n 个线性无关特征向量；等价于每个特征值几何重数等于代数重数。
- 易错边界：特征值互异只是充分条件；重根不等于不可对角化。
## 7.16 实对称矩阵谱定理

- 条件与结论：实对称矩阵的特征值为实数，异特征值特征向量正交，且存在正交矩阵将其对角化。
- 易错边界：一般实矩阵不享有这些结论；正交对角化要求特征向量单位化。
## 7.17 Sylvester 惯性定理与正定判据

- 条件与结论：实对称矩阵在可逆合同变换下正负惯性指数不变；正定可用特征值全正或顺序主子式全正判定。
- 易错边界：合同与相似不可混用；顺序主子式判据针对实对称矩阵。
## 7.18 全概率与 Bayes

- 条件与结论：完备事件组 B_i 两两互斥且并为全集、P(B_i)>0；先用全概率求结果概率，再用 Bayes 反推原因。
- 易错边界：分母是所有原因贡献之和，不能只保留目标原因。
## 7.19 独立性判据

- 条件与结论：离散/连续二维变量独立时联合分布等于边缘分布乘积，并且支撑结构一致。
- 易错边界：不相关一般不独立；两两独立不等于相互独立。
## 7.20 大数定律与中心极限定理

- 条件与结论：大数定律要求相应独立同分布与矩条件；Lindeberg-Levy CLT 要求 i.i.d. 且均值、方差有限。
- 易错边界：大数定律给收敛，CLT 给标准化后的近似分布，目标不同。
## 7.21 正态总体抽样分布

- 条件与结论：正态样本下 X̄ 与 S² 独立，X̄ 正态，(n-1)S²/σ² 服从 χ²；进一步构造 t 与 F。
- 易错边界：这些精确结论依赖总体正态；自由度由独立信息数决定。
