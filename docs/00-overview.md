## 试卷定位（现行近年结构）

- 满分 150 分，考试时间 180 分钟。
- 题型通常为：10 道单项选择题（50 分）、6 道填空题（30 分）、6 道解答题（70 分）。
- 内容比例通常为：高等数学约 60%，线性代数约 20%，概率论与数理统计约 20%。
- 本框架的目标不是押题，而是覆盖大纲并建立跨章节连接。

## 使用方法

### 掌握等级
- **0 未接触**：只知道名称或完全陌生；下一步：看概念与例题，建立最小框架。
- **1 已理解**：能复述定义和定理，但独立做题不稳；下一步：完成基础例题与定义辨析。
- **2 会基础**：常规单点题可做，综合题会卡；下一步：做题型归纳，补方法触发条件。
- **3 会综合**：跨节点题能独立完成，但速度或稳定性不足；下一步：限时训练与错因归类。
- **4 稳定**：真题中能快速识别、正确率高、可讲清；下一步：间隔复习，防遗忘。

### 优先级
- **A+**：底层核心或高综合度节点，必须达到 3—4 级。
- **A**：主要考点，至少达到 3 级。
- **B**：低频或依赖前置内容的节点，至少达到 2 级。
- **C**：拓展理解，用于处理陌生变式，不应挤占主线时间。

### 知识卡字段
每个节点长期维护六项：①概念与定义；②定理及条件；③计算/证明方法；④典型题型；⑤易错边界；⑥掌握证据。

## 总依赖图
- **高等数学 H（H0—H10）**：极限 → 微分 → 积分 → 微分方程/空间几何 → 多元微分 → 重积分 → 曲线曲面积分 → 级数 → 综合。
- **线性代数 L（L0—L7）**：统一语言 → 行列式/矩阵 → 向量组 → 方程组 → 特征值与相似 → 二次型 → 关系网。
- **概率统计 P（P1—P9）**：事件概率 → 一维分布 → 联合分布 → 数字特征 → 极限定理 → 抽样分布 → 估计 → 检验 → 综合。
- **方法库 M（M1—M7）**：定义条件 → 对称 → 参数 → 存在唯一 → 变换降维 → 证明模板 → 计算稳定性。
