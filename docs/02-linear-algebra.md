# 第二部分 线性代数（L）

线性代数的核心不是六章公式，而是一张关系网：行列式判断可逆，秩控制解空间维数，特征值描述相似结构，二次型研究对称矩阵在合同变换下的性质。

**本章目标：** 先建立线代的统一视角，避免把行列式、方程组、特征值学成互不相干的技巧。

### 核心讲解1：矩阵、向量组与方程组是同一线性映射的三种视角

**为什么成立**：矩阵 A 既可以看成数表，也可以看成把向量 x 映到 Ax 的线性变换。它的列向量描述所有可能输出的生成元，因此 `Ax=b` 有解恰好表示 b 属于列空间；齐次解构成零空间，记录哪些输入被压到零。消元研究方程，线性组合研究列向量，空间语言则把两者统一起来。

**怎么用**：看到矩阵先标尺寸 `m×n`：输入空间维数 n，输出空间维数 m。问方程有解就看 b 是否在列空间；问齐次自由度就看零空间；问向量组秩就把向量作列组成矩阵。选择行变换求解时记住它改变列向量本身，却保持方程约束的等价性和秩。

**小例题 / 路线演示**：令 `A=[[1,2],[2,4]]`。两列相关，列空间是一条直线，秩为 1；`Ax=b` 只有当 `b₂=2b₁` 时有解。零空间由 `x₁+2x₂=0` 给出，维数 `2-1=1`。一个简单矩阵同时展示了列空间控制相容性、零空间控制自由度。

**哪里会失效**：把行变换后的矩阵列空间当成原列空间会出错：行变换保持列之间的线性关系和秩，但通常改变列空间在外部坐标中的具体位置。相同秩只说明映射压缩到相同维数，不说明零空间、列空间或方程解集相同。

### 核心讲解2：不变量必须与变换类型配对

**为什么成立**：不同等价关系回答不同问题。初等行变换对应方程约束的重新组合，保持秩和解集；相似变换是同一线性变换在不同基下的矩阵表示，保持特征结构；合同变换来自二次型变量替换，保持正负惯性指数。行列式、秩、特征值和惯性指数因此各自有适用语境。

**怎么用**：先问题目改变的是方程、基还是二次型变量。求解与秩用初等变换；研究线性算子的谱和幂用相似；化二次型标准形用合同。每做一步都列出它保证保持什么、不保证保持什么，尤其区分 `P^{-1}AP` 与 `CᵀAC`。

**小例题 / 路线演示**：交换单位矩阵的两行得到交换矩阵。它们行等价且秩相同，但特征值从 `1,1` 变成 `1,-1`，说明行变换不保持特征值。另一方面，若 `B=P^{-1}AP`，A、B 表示同一线性变换，特征多项式相同。

**哪里会失效**：相同特征多项式并不必然相似，例如零矩阵与非零二阶幂零矩阵都可有特征多项式 `λ²`，但秩不同。相同秩的二次型也不必合同到相同规范形，因为正负项个数可能不同。只背“不变量”而不写变换类型，会把必要条件误作充分条件。

### 章末路线选择

1. 先标矩阵尺寸与输入、输出空间。
2. 在矩阵、向量组、方程组三种语言间选择最直接视角。
3. 用列空间判断相容性，用零空间判断自由度，用秩连接二者。
4. 先判变换类型，再调用相应不变量。

### 达标标准

- 能解释 Ax=b、列空间和线性表示之间的等价关系。
- 能正确写出零空间维数 n-r，而不混淆行列数。
- 能区分初等变换、相似与合同所保持的性质。

### 核心讲解1：行列式是有向体积缩放因子

**为什么成立**：方阵 A 把单位立方体变成由列向量张成的平行多面体，`det A` 的绝对值是体积倍率，符号记录定向。列向量相关时图形塌缩到低维，体积为零；交换两列翻转定向，行列式变号；一列倍乘使对应边长倍乘。这些几何事实正好对应行列式的交替多线性。

**怎么用**：计算前先找三角、比例、相同行列或可制造的零。倍加一行不改变行列式，交换行变号，某行提因子要乘到行列式外。按行展开时优先零最多的行列；参数题把结果看成参数多项式，用次数、根和特殊值检查。

**小例题 / 路线演示**：矩阵列向量 `a,b,a+b` 的行列式为零，因为第三列是前两列线性组合；用线性性也可写成 `det(a,b,a)+det(a,b,b)=0`。这个结论不需把所有元素展开，说明结构识别比排列定义更高效。

**哪里会失效**：把某行乘 k 后忘记行列式也乘 k，会破坏体积倍率；把一行加到另一行却额外乘系数，同样混淆性质。`det(A+B)` 一般不等于 `det A+det B`，因为多线性是对单独一行或一列，而不是对整个矩阵同时线性。

### 核心讲解2：展开、递推与分块都在制造低维问题

**为什么成立**：Laplace 展开沿一行或一列把 n 阶行列式化为若干 `n-1` 阶子式；递推行列式通过稀疏结构把相邻阶连接；分块技巧则把大的线性变换按子空间拆开。Schur 补公式本质上是分块消元，必须先用可逆块消去一部分变量。

**怎么用**：箭形或三对角结构先从首末行展开建立递推；Vandermonde 结构用两根相同即为零和最高次系数识别。分块三角矩阵直接乘对角块行列式；一般块矩阵若 A 可逆，可用块消元得到 `det A·det(D-CA^{-1}B)`。

**小例题 / 路线演示**：对块矩阵 `[[A,B],[C,D]]` 且 A 可逆，左乘行列式为 1 的块初等矩阵 `[[I,0],[-CA^{-1},I]]`，得到上三角块 `[[A,B],[0,D-CA^{-1}B]]`，于是行列式为 `det A det(D-CA^{-1}B)`。公式直接来自消元。

**哪里会失效**：没有 A 可逆条件就不能写 `A^{-1}`；即使块尺寸相容，`det([[A,B],[C,D]])=det(AD-BC)` 也通常要求额外交换条件，不能照搬二阶标量公式。递推求出通式后还要核对初始阶，否则常数会错。

### 章末路线选择

1. 先找零、比例、线性组合、三角和分块结构。
2. 用行列性质制造稀疏，再选展开或递推。
3. 分块公式先写尺寸与可逆条件，不套标量二阶公式。
4. 用次数、特殊参数值和可逆性含义复核结果。

### 达标标准

- 能从体积和线性相关解释 detA=0。
- 能稳定区分交换、倍乘和倍加对行列式的影响。
- 能推导并正确使用带可逆条件的 Schur 补。

### 核心讲解1：矩阵乘法表示线性变换复合，顺序不能交换

**为什么成立**：`ABx=A(Bx)` 表示先做 B 再做 A，因此乘法顺序记录操作顺序。尺寸规则来自中间空间必须匹配；转置把输入输出交换，所以 `(AB)ᵀ=BᵀAᵀ`。逆矩阵是能撤销映射的双侧变换，只有方阵满秩时存在。矩阵不是普通数，不能随意换位或约分。

**怎么用**：写乘积前在矩阵旁标尺寸。解 `AX=B` 若 A 可逆只能左乘 `A^{-1}`，解 `XA=B` 则右乘；不可逆时按 B 的每一列转成方程组判断相容性与自由度。求逆可把 `[A|I]` 行化简，过程同时是在寻找把 A 变成 I 的初等矩阵乘积。

**小例题 / 路线演示**：令 `A=[[1,1],[0,1]]`, `B=[[1,0],[1,1]]`，直接算得 AB 与 BA 不同。若方程 `AX=I` 可解，X 就是 A 的右逆；有限维方阵中右逆推出满秩，因而也是左逆。这个结论依赖方阵，长方矩阵可能只有单侧逆。

**哪里会失效**：由 `AB=AC` 不能在 A 不可逆时约去 A；取 A 为零因子即可反例。`(A+B)^{-1}` 一般不等于 `A^{-1}+B^{-1}`。初等行变换等于左乘初等矩阵，若误作右乘，改变的是列而非方程约束。

### 核心讲解2：秩测量有效方向，并控制方程与乘积

**为什么成立**：秩是列空间或行空间的维数，表示线性映射能保留多少个独立方向。乘积 AB 的像包含在 A 的像中，同时 B 的输入先被压到 B 的像，所以 `r(AB)≤min(r(A),r(B))`。秩与零空间通过 `dim N(A)+r(A)=n` 连接，直接决定齐次自由变量数。

**怎么用**：计算秩优先做阶梯形并记录参数导致的主元变化；证明秩不等式使用像空间包含或零空间包含。矩阵方程先比较尺寸和秩，再判断是否能有解。涉及伴随矩阵时按 `r(A)=n,n-1,<n-1` 分类，因为余子式阶数会突然改变。

**小例题 / 路线演示**：若 A 为 `m×n`、B 为 `n×p`，则 `N(B)⊆N(AB)`，所以 AB 的零空间至少与 B 一样大；结合秩—零空间定理可得 `r(AB)≤r(B)`。另一方面 `Col(AB)⊆Col(A)` 给 `r(AB)≤r(A)`，两条包含共同得到上界。

**哪里会失效**：`r(A+B)=r(A)+r(B)` 一般不成立，取 B=-A 即得反例；正确的是上界不等式。相同秩不表示相同列空间或零空间。用一个非零子式只能证明秩至少多大，要证明恰好还需所有更高阶子式为零或阶梯形无更多主元。

### 核心讲解3：分块与特殊矩阵把大问题压缩到小代数

**为什么成立**：分块矩阵不是装饰，而是按子空间分解线性变换。对角块独立作用于不同子空间，幂和逆可逐块处理；幂等矩阵满足 `P²=P`，把空间投影到像空间；幂零矩阵经过有限次复合归零；正交矩阵保持长度和角度。这些代数恒等式会限制特征值、秩和多项式。

**怎么用**：先检查块尺寸与零块位置，再像普通矩阵一样按顺序乘块。遇 `A²=A`、`AᵀA=I`、`A^k=0` 等关系，先用低次多项式降幂，再求逆或高次幂。分块逆可通过乘回单位矩阵验证，不必死记全部公式。

**小例题 / 路线演示**：若 `P²=P`，则空间可分为 `Im P` 与 `Ker P`：任意 x 写成 `Px+(x-Px)`，前者在像中，后者被 P 映为 0。于是 P 在适当基下相似于 `diag(I_r,0)`，特征值只能是 0 或 1，也解释了 `tr P=r(P)`。

**哪里会失效**：块矩阵乘法仍不交换，块本身也通常不交换。由 `A²=A` 不能推出 A=0 或 I，非平凡投影就是反例。正交矩阵行列式只能是 ±1，不一定为 1；伴随矩阵公式 `A*=det(A)A^{-1}` 只在 A 可逆时可直接使用。

### 章末路线选择

1. 所有运算先标尺寸和左右顺序。
2. 识别可逆、秩、分块与特殊多项式结构，再决定计算。
3. 矩阵方程按列转方程组，参数值从主元变化处分类。
4. 秩结论优先用像空间或零空间包含证明。

### 核心讲解1：线性无关表示坐标表达的唯一性

**为什么成立**：向量组无关意味着只有全零系数能组合成零，因此同一向量若能由该组表示，系数必唯一；相关则存在非平凡零组合，其中至少一个向量可由其余向量表示。极大无关组既不冗余又能张成原向量组，所含向量数就是秩。基把抽象空间变成坐标，维数是不依赖具体基的数量。

**怎么用**：把向量作列组成 A，解 `Ac=0`：只有零解则无关，有自由变量则相关。判断 β 是否可表示，解 `Ac=β`；若列无关，表示一旦存在便唯一。选极大无关组时对 A 行化简找主元列编号，再回到原矩阵取对应列。

**小例题 / 路线演示**：在 R³ 中，`v₁=(1,0,1),v₂=(0,1,1),v₃=(1,1,2)` 满足 `v₃=v₁+v₂`，所以相关，秩为 2；`v₁,v₂` 是一个极大无关组。向量 `(a,b,a+b)` 在其张成平面中的坐标唯一为 `(a,b)`。

**哪里会失效**：极大无关组不唯一，但所含向量数相同；把“某个极大组不同”误作秩不同是概念错误。行化简保持列间相关关系，却改变具体列向量，所以主元列要从原矩阵选。零向量所在向量组必相关，不能作为基元素。

### 核心讲解2：子空间、正交与维数公式组织空间关系

**为什么成立**：子空间必须对加法和数乘封闭。两个子空间的和收集所有 `u+v`，交收集公共向量；重复部分在相加维数时被算了两次，因此 `dim(U+V)=dimU+dimV-dim(U∩V)`。正交基让坐标由内积直接投影，Schmidt 过程逐步减去已有方向分量。

**怎么用**：判断集合是否子空间先查零向量与线性封闭。求和空间把两组基合并后取极大无关组；求交空间可令两边线性组合相等，解系数方程。Schmidt 每一步用原向量减去对已有正交向量的投影，再单位化；若余量为零说明原组相关。

**小例题 / 路线演示**：R³ 中 U 为 xy 平面，V 为 yz 平面。它们维数均为 2，交为 y 轴维数 1，所以和空间维数为 `2+2-1=3`，即整个 R³。这个例子直观展示了维数公式中为何要减去公共方向。

**哪里会失效**：两个子空间的并一般不是子空间：x 轴和 y 轴的并含 `(1,0)`、`(0,1)`，却不含其和 `(1,1)`。Schmidt 的投影分母要求已有向量非零；未单位化时要除以自身内积，不能直接照搬单位向量公式。

### 章末路线选择

1. 向量作列，统一用 Ac=0 和 Ac=b 判断无关与表示。
2. 主元列编号从阶梯形读取，基向量回到原矩阵选择。
3. 子空间和用基合并，交用方程联立，并用维数公式复核。
4. 正交化逐次减投影，最后检查正交与单位长度。

- 能从零组合解释线性无关与表示唯一。
- 能稳定选出极大无关组并计算向量组秩。
- 能在基表示和方程表示之间转换子空间。
- 能完整执行 Schmidt 正交化并解释每一步。

### 核心讲解1：秩同时决定相容性和自由度

**为什么成立**：方程 `Ax=b` 要求 b 是 A 的列向量线性组合，因此有解当且仅当增广列不增加秩，即 `r(A)=r(A|b)`。相容后，n 个未知量中有 r 个主元变量，其余 `n-r` 个自由变量参数化全部解；若 r=n，自由度为零，解唯一。齐次方程 b=0 总相容，其解空间维数为 `n-r(A)`。

**怎么用**：先标 n，再对增广矩阵只做行变换。阶梯形出现 `[0…0|c]` 且 `c≠0` 即无解；否则统计主元数 r。唯一解要求 r=n，无穷多解要求 r<n。写通解时先选自由变量，解出主元变量，并把参数向量个数与 `n-r` 对上。

**小例题 / 路线演示**：方程 `x+y+z=1, 2x+2y+2z=2` 只有一个独立约束，`r(A)=r(A|b)=1<n=3`，所以有两个自由变量。取 y=s,z=t，则 `x=1-s-t`，通解为 `(1,0,0)+s(-1,1,0)+t(-1,0,1)`。

**哪里会失效**：`r(A)=r(A|b)` 只说明有解，不说明唯一；还必须与 n 比较。把矩阵行数 m 当未知量数会把自由度写成 `m-r`。参数消元时若除以 `a-1`，必须先分出 `a=1`，否则可能删掉秩下降和解数变化的关键情形。

### 核心讲解2：非齐次解集是特解平移后的零空间

**为什么成立**：若 `Ax_p=b` 且 `Ax_h=0`，则 `A(x_p+x_h)=b`；反过来任意两个非齐次解之差满足齐次方程。因此非齐次解集不是过原点的线性空间，而是把零空间整体平移到某个特解处得到的仿射空间。这一结构统一了通解、同解、公共解与解集包含问题。

**怎么用**：先找一个方便的特解，再求对应齐次基础解系。比较两个非齐次系统是否同解，要同时比较零空间和选定特解所属的仿射平移；公共解把两组方程纵向合并；解集包含可转成每条目标约束都是来源约束的线性组合，并检查常数项兼容。

**小例题 / 路线演示**：若 `Ax=b` 有特解 p，零空间为 N，则全部解是 `p+N`。另一个系统 `Cx=d` 与它同解，当且仅当两者方向空间相同且某个共同点一致。仅有 `N(A)=N(C)` 还不够，例如实数上一元方程 `x=0` 与 `x=1` 的齐次方向都为零，却不是同一解集。

**哪里会失效**：两个非齐次解相加满足右端 `2b`，不是 b；正确封闭操作是特解加齐次解，或两个特解作差。相同秩的系统可以有完全不同的行空间和解集。无解系统没有“特解 + 齐次解”的表示，必须先完成相容性判断。

### 核心讲解3：参数与反推题围绕主元改变分类

**为什么成立**：参数变化只有在某个候选主元为零、增广矛盾出现或消失时才改变秩和解结构。因此无需对每个参数值重新消元，只需保留含参因子，找出所有临界值，再在一般情形和临界情形分别化简。由解反推矩阵时，解向量给出零空间或仿射解集信息，可转成行空间约束。

**怎么用**：消元时不除含参因子，将其留在主元位置并收集零点。一般参数值按非零处理，临界值逐个代回原增广矩阵重算。已知齐次基础解系时先确定零空间，再取其正交补作为行空间；已知非齐次解集时用解之差恢复零空间，再用一个特解处理常数项。

**小例题 / 路线演示**：系统 `x+ay=1, ax+y=1` 的系数行列式为 `1-a²`。当 `a≠±1` 唯一解；`a=1` 时两式相同，有无穷多解；`a=-1` 时两左端互为相反数而右端同为 1，产生矛盾无解。两个临界值必须分别代回，不能统称“行列式为零所以无穷多”。

**哪里会失效**：行列式为零只排除唯一解，非齐次系统可能无解也可能无穷多。由若干已知解向量不能直接说它们就是基础解系，还需验证线性无关且数量等于 `n-r`。反推参数时若只满足给定解，不检查是否出现额外解，容易把“包含”误作“等于”。

### 章末路线选择

1. 先写 n、r(A)、r(A|b)，再判无解、唯一或无穷多。
2. 参数消元保留可能为零的因子，临界值代回原矩阵。
3. 相容后按特解加齐次基础解系写通解。
4. 同解、公共解和包含题统一转为空间与仿射平移关系。

- 能把自由变量数与 n-r 精确对应。
- 能区分非齐次解集与线性空间。
- 能完整处理参数主元退化的全部临界值。

### 核心讲解1：特征向量是不改变方向的变换轴

**为什么成立**：方程 `Av=λv` 表示线性变换对 v 只缩放不转向。它等价于 `(A-λI)v=0` 有非零解，所以 λ 必须使 `det(A-λI)=0`。特征值之和为迹、乘积为行列式，来自特征多项式系数；不同特征值的特征向量线性无关，因为它们对应不同缩放规律。

**怎么用**：先利用三角矩阵对角元、迹、行列式或已知不变子空间猜谱，再算特征多项式。每个 λ 都单独解 `N(A-λI)`，不能只求根不求向量。检查结果时比较特征值和与迹、积与行列式，并把向量代回 `Av=λv`。

**小例题 / 路线演示**：矩阵 `A=[[2,1],[0,3]]` 的特征值由三角结构直接得 2、3。λ=2 时解得向量沿 x 轴；λ=3 时可取 `(1,1)`。两向量独立，所以它们构成一组基，在该基下 A 只做两个方向的独立缩放。

**哪里会失效**：解 `det(A-λI)=0` 只得到特征值，若根重复还必须检查特征子空间维数。零向量满足形式等式却不被定义为特征向量，因为它没有方向。对 A 做行化简后再读取对角元求谱是错误的，行变换通常改变特征值。

### 核心讲解2：可对角化取决于是否拥有完整特征向量基

**为什么成立**：若 n 个线性无关特征向量组成 P 的列，则 `AP=PΛ`，等价于 `P^{-1}AP=Λ`。因此可对角化的本质不是特征值是否好看，而是特征向量是否足够。每个特征值的几何重数不超过代数重数；二者对每个根都相等时，所有特征子空间维数相加为 n。

**怎么用**：特征值互异可直接判可对角化；有重根时逐个计算 `dim N(A-λI)`。构造 P 时把特征向量按与 Λ 对角元相同顺序排列。实对称矩阵可用谱定理直接正交对角化，但仍要在重特征空间内选标准正交基。

**小例题 / 路线演示**：单位矩阵只有特征值 1，代数重数 n，但特征子空间是整个空间，几何重数也为 n，所以可对角化。二阶 Jordan 块 `[[1,1],[0,1]]` 同样只有根 1，却只有一维特征子空间，缺少第二条特征方向，不能对角化。

**哪里会失效**：“有重根所以不可对角化”被单位矩阵立即反驳；“特征值全不同才可对角化”则把充分条件误作必要条件。P 的列顺序若与 Λ 不一致，`AP=PΛ` 会失败。一般实矩阵不保证存在正交特征向量基，不能套实对称结论。

### 核心讲解3：相似把矩阵幂和多项式变成标量运算

**为什么成立**：相似矩阵表示同一线性变换在不同基下的坐标。若 `A=PΛP^{-1}`，则 `A^k=PΛ^kP^{-1}`，复杂矩阵幂化成对角元幂；更一般地 `p(A)=Pp(Λ)P^{-1}`。即使不可对角化，特征多项式或已知低次关系也能把高次幂除余成有限个低次矩阵组合。

**怎么用**：先判断是否值得对角化：谱简单且需计算高次幂时优先。若只给 `A²=aA+bI`，直接建立递推或对多项式除以关系式。参数相似题先比较迹、行列式、秩和特征子空间维数；这些不变量不同即可否定，相同仍需构造或进一步检查。

**小例题 / 路线演示**：若 A 可对角化且特征值为 1、2，则多项式 `p(A)` 的特征值为 `p(1),p(2)`；计算 `A^{100}` 时只需把 1、2 提到 100 次再换基。若已知 `(A-I)(A-2I)=0`，也可把任意高次幂化为 `αA+βI`。

**哪里会失效**：λ 是 A 的特征值时 p(λ) 一定是 p(A) 的特征值，但反向讨论重数和全部谱时要谨慎。特征多项式相同只是相似的必要条件；Jordan 结构或各特征子空间维数不同仍不相似。不可逆的特征向量矩阵 P 不能用于相似变换。

### 章末路线选择

1. 先用迹、行列式和结构信息缩小特征值计算。
2. 每个特征值单独求特征子空间，重根必查维数。
3. 可对角化看独立特征向量总数，实对称矩阵走正交对角化。
4. 矩阵幂比较对角化与低次多项式降幂两条路线。

### 达标标准

- 能从不变方向解释特征值定义。
- 能用几何重数和代数重数判断可对角化。
- 能正确构造 P 与 Λ 并保持列顺序。
- 能用谱或多项式关系稳定计算矩阵幂。

### 核心讲解1：二次型只看矩阵的对称部分

**为什么成立**：标量 `xᵀAx` 中，反对称部分满足 `xᵀ(A-Aᵀ)x=0`，所以二次型完全由 `(A+Aᵀ)/2` 决定。展开时 `x_ix_j` 的系数是 `a_ij+a_ji`；采用对称矩阵后就是 `2a_ij`。这解释了交叉项为什么要平分，也让谱定理和正交变换可以使用。

**怎么用**：从多项式写矩阵时，对角项直接放系数，交叉项一半放到两个对称位置。反向展开时交叉项乘 2。先检查 A 是否对称；若题给非对称 A，先换成对称部分。化标准形前明确变换是 `x=Cy`，矩阵变为 `CᵀAC`。

**小例题 / 路线演示**：二次型 `x₁²+4x₁x₂+3x₂²` 的对称矩阵是 `[[1,2],[2,3]]`，因为两个非对角元共同给出 `4x₁x₂`。若误填 4，会在展开时得到 8，后续特征值与正定性全部错误。

**哪里会失效**：一般非对称矩阵的特征值不能直接作为二次型正定判据；必须先取对称部分。把交叉项系数完整填入上下两个位置会重复计算。变量替换若不可逆，可能降低维数和秩，不再是合同等价，不能用惯性定律。

### 核心讲解2：合同化标准形保持正负惯性，不保持特征值

**为什么成立**：可逆变量替换 `x=Cy` 把同一个二次型改写为 `yᵀ(CᵀAC)y`，因此改变坐标但不改变函数取正、取负方向的最大维数。Sylvester 惯性定律说明标准形中正平方、负平方和零项数固定。正交变换是特殊合同，同时因 `C^{-1}=Cᵀ` 也构成相似，故还能保留特征值。

**怎么用**：只求标准形可用配方法，速度快但要保留完整可逆换元；要求正交变换则求实对称 A 的特征值和标准正交特征向量，以它们为列构造 Q。规范形再把非零系数缩放为 ±1，读出正负惯性指数。

**小例题 / 路线演示**：`2x₁²+4x₁x₂+2x₂²=2(x₁+x₂)²`，标准形只有一个正平方和一个零项，秩为 1、正惯性指数 1。虽然原式含两个变量，它只在方向 `(1,1)` 上有能量，在正交方向 `(1,-1)` 上为零。

**哪里会失效**：相似变换 `P^{-1}AP` 与合同 `CᵀAC` 形式不同，前者保谱，后者保惯性。仅仅得到对角矩阵还要说明变换是否可逆。配方中若除以可能为零的参数系数，必须先分类，否则会漏掉秩和惯性突变。

### 核心讲解3：正定意味着每个非零方向都有正二次能量

**为什么成立**：实对称 A 正定的定义是对所有非零 x 都有 `xᵀAx>0`。正交对角化后，这等价于所有特征值正；Sylvester 判据又把它化为全部顺序主子式正。三种判据分别适合概念证明、谱已知和元素计算。Hessian 正定给多元函数驻点的严格局部极小，正是同一二次主部结构。

**怎么用**：先确认实对称。二阶或低阶元素矩阵优先顺序主子式；已知谱或易对角化时看特征值；要求证明可直接配方成正平方和。半正定需要所有特征值非负或所有主子式非负，不能只把“顺序主子式全正”机械改成“全非负”。

**小例题 / 路线演示**：A=`[[2,1],[1,2]]` 的顺序主子式为 2 和 3，均正，因此正定；特征值为 3、1 也验证。对应二次型 `2x²+2xy+2y²=(x+y)²+x²+y²` 对非零向量严格为正。

**哪里会失效**：`detA>0` 只说明特征值乘积正，可能全部负，例如 `diag(-1,-1)` 行列式为 1 却负定。一般实矩阵即使特征值全正，`xᵀAx` 也可能不正定，因为正定判据针对对称部分。半正定时顺序主子式非负不是充分条件。

### 章末路线选择

1. 先把二次型写成正确的实对称矩阵。
2. 按目标选择配方法、合同标准形或正交对角化。
3. 用秩和正负惯性指数复核标准形。
4. 正定判别先确认对称，再选定义、特征值或顺序主子式。

### 核心讲解1：可逆性等价链把代数、方程和谱连在一起

**为什么成立**：对 n 阶方阵，`detA≠0`、`r(A)=n`、零空间只有零向量、每个 b 的 `Ax=b` 有唯一解、A 可逆以及 0 不是特征值互相等价。它们分别说体积不塌缩、独立方向完整、输入不被压零、映射一一且满射，以及没有零缩放方向，本质都是同一个“信息没有损失”。

**怎么用**：综合题先尝试把已知条件接入等价链。例如证明 A 可逆，可证零空间只有零向量；判断非零特征值，可看行列式；方程唯一解可转满秩。写证明时至少给出所用箭头的理由，不把整条链当黑箱。长方矩阵则拆成满列秩与满行秩，不套方阵等价。

**小例题 / 路线演示**：若 `A²x=0` 只可能 x=0，则对任意 `Ax=0` 也有 `A²x=0`，故 x=0，A 的零空间平凡；方阵因此满秩可逆。这个证明没有展开行列式，而是沿零空间包含接入可逆等价链。

**哪里会失效**：对长方矩阵，左逆与右逆不必同时存在，`r(A)=n` 也要先说明 n 是列数。`detA=0` 只说明 0 是特征值和不可逆，不直接给零空间具体基。等价链仅在同阶方阵语境完整成立。

### 核心讲解2：空间包含和特征向量作用是综合证明的两把钥匙

**为什么成立**：乘积满足 `N(B)⊆N(AB)` 与 `Col(AB)⊆Col(A)`，可把秩问题化成空间维数；矩阵多项式作用在特征向量上满足 `p(A)v=p(λ)v`，可把谱问题化成标量多项式。`AᵀA` 还满足 `xᵀAᵀAx=|Ax|²`，因此零空间与 A 相同且半正定，把秩、谱和二次型连在一起。

**怎么用**：遇 `AB=0` 先写 `Im B⊆N(A)`，再比较维数；遇 `AᵀA` 先用平方范数；遇 `p(A)` 先作用到已知特征向量。证明充分性困难时尝试逆否，否定命题则从 2×2 的对角、幂零、投影或交换矩阵中找最小反例。

**小例题 / 路线演示**：证明 `N(AᵀA)=N(A)`：若 Ax=0 显然成立；反之 `AᵀAx=0`，左乘 `xᵀ` 得 `|Ax|²=0`，所以 Ax=0。于是两矩阵零空间维数相同、列数相同，秩也相同。

**哪里会失效**：λ 是 A 的特征值能推出 p(λ) 是 p(A) 的特征值，但不同 λ 可能映到同一个 p(λ)，重数信息不能简单一一搬运。`AB=0` 不推出 A 或 B 为零，只说明像空间落入零空间。最小反例必须满足题设全部条件，不能通过破坏前提来否定命题。

### 章末路线选择

1. 先寻找可逆性等价链能否直接接入。
2. 乘积秩写像空间与零空间包含，AᵀA 写平方范数。
3. 矩阵多项式作用于特征向量，把问题降成标量关系。
4. 逆命题不明时优先检查最小维反例并核对全部前提。
