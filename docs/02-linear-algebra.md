# 第二部分 线性代数（L）

线性代数的核心不是六章公式，而是一张关系网：行列式判断可逆，秩控制解空间维数，特征值描述相似结构，二次型研究对称矩阵在合同变换下的性质。

## L0 全局语言：秩、空间与变换｜优先级 A+

**本章目标：** 先建立线代的统一视角，避免把行列式、方程组、特征值学成互不相干的技巧。

### 知识节点
- L0.1 三种对象：矩阵、向量组、线性方程组；三者通过列空间、零空间和线性映射连接。
- L0.2 四个核心量：det(A)、r(A)、特征值、正负惯性指数。
- L0.3 三类变换：初等变换、相似变换、合同变换；允许保持的性质不同。
- L0.4 维数思想：未知量个数 n、秩 r、齐次解空间维数 n−r。

### 核心方法
- 每道线代题先判断研究对象和允许的变换，再选择行变换、相似或合同。

### 典型题型
- 概念判断
- 关系链证明
- 反例选择

### 高频易错边界
- 把相似与合同混用
- 把行等价误当相似
- 忽视矩阵尺寸

### 达标标准
能用自己的话解释 det、rank、eigenvalue 分别在回答什么问题。

## L1 行列式｜优先级 A

**本章目标：** 熟练计算并理解其作为‘可逆性标志’的结构意义。

### 知识节点
- L1.1 n 阶行列式定义、排列与符号；通常以性质和展开为主。
- L1.2 基本性质：转置、交换行列、倍乘、倍加、线性拆分。
- L1.3 按行/列展开；代数余子式；某行与另一行余子式乘积和为零。
- L1.4 特殊行列式：三角、对角、Vandermonde、箭形、循环/递推结构。
- L1.5 分块行列式与 Schur 补（在可逆条件下）。
- L1.6 det(AB)、det(A^T)、det(A^{-1})、det(kA)、det(A*)。
- L1.7 Cramer 法则及其与唯一解的关系。

### 核心方法
- 计算优先造零或提取公因子；参数行列式优先找线性相关临界值。
- 看到 A+uv^T、分块矩阵时先考虑行列式引理或 Schur 补，但必须检查尺寸与可逆条件。

### 典型题型
- 数值/参数行列式
- 余子式求和
- 分块行列式
- 可逆性判断

### 高频易错边界
- 行倍加与行倍乘性质混淆
- det(A+B)=det A+det B 的错误
- Schur 补漏可逆条件

### 达标标准
普通行列式 3—5 分钟内算完；结构题能说明为何采用该变形。

## L2 矩阵｜优先级 A+

**本章目标：** 掌握矩阵运算、逆、秩和分块，为方程组与特征值奠基。

### 知识节点
- L2.1 矩阵运算及不交换性；转置与乘积转置。
- L2.2 逆矩阵：定义、存在条件、伴随矩阵法、初等变换法。
- L2.3 初等矩阵与初等变换；左乘做行变换，右乘做列变换。
- L2.4 矩阵的秩：子式定义、阶梯形、满秩分解、秩不等式。
- L2.5 分块矩阵：乘法、逆、幂与结构简化。
- L2.6 矩阵方程：AX=B、XA=B、AXB=C；可逆与不可逆情形。
- L2.7 特殊矩阵：对称、反对称、正交、幂等、幂零；性质辨析。
- L2.8 伴随矩阵 A* 的秩、特征值和与 A 的关系。

### 核心方法
- 求逆优先看结构：对角/分块/初等矩阵乘积；一般情况再增广变换。
- 秩题统一转化为初等变换或非零子式；乘积秩同时看上界与 Sylvester 下界。

### 典型题型
- 求逆与矩阵方程
- 秩的计算/证明
- 分块矩阵
- 伴随矩阵
- 特殊矩阵性质

### 高频易错边界
- 矩阵乘法擅自交换
- 右乘逆矩阵时顺序错误
- 把 AB=0 推成 A=0 或 B=0
- 伴随矩阵秩分类漏 n=1

### 达标标准
能稳定处理矩阵方程的乘法顺序；对秩关系能给出上下界而非只猜等号。

## L3 向量组与线性空间｜优先级 A+

**本章目标：** 掌握线性相关、极大无关组、基与坐标的维数语言。

### 知识节点
- L3.1 线性组合、线性表示、等价向量组。
- L3.2 线性相关与无关：定义、判定、增删向量后的变化。
- L3.3 极大线性无关组与向量组秩。
- L3.4 矩阵行秩等于列秩；行空间、列空间。
- L3.5 向量空间、子空间、基、维数、坐标与过渡矩阵。
- L3.6 正交向量组、标准正交基、Schmidt 正交化。
- L3.7 两个子空间的和与交：维数公式及方程表示。

### 核心方法
- 向量组判相关可转为齐次方程；是否能表示可转为非齐次方程。
- 题中出现‘任意向量’‘所有解’时优先想空间与维数，而非逐个计算。

### 典型题型
- 相关性判断
- 极大无关组
- 基与坐标
- 子空间交并
- 正交化

### 高频易错边界
- 向量个数大于维数才一定相关，反向不成立
- 把向量组等价与矩阵等价混淆
- 坐标变换方向写反

### 达标标准
能从矩阵阶梯形同时读出秩、主元列、极大无关组和方程自由变量。

## L4 线性方程组｜优先级 A+

**本章目标：** 把解的存在、唯一、无穷多与秩和零空间维数统一。

### 知识节点
- L4.1 齐次方程 Ax=0：必有零解；非零解条件 r(A)<n。
- L4.2 基础解系与通解；基础解系所含向量数 n−r(A)。
- L4.3 非齐次方程 Ax=b：有解条件 r(A)=r(A|b)。
- L4.4 非齐次通解：一个特解 + 对应齐次通解。
- L4.5 参数方程组：秩随参数变化的分类。
- L4.6 同解、公共解、解集包含；行空间/零空间条件。
- L4.7 矩阵方程与多右端方程组。
- L4.8 由解反推系数矩阵、秩或参数。

### 核心方法
- 方程组题先写三个数：未知量个数 n、系数秩 r(A)、增广秩 r(A|b)。
- 同解问题不能只比较秩，还要比较零空间或行空间；非齐次还需验证特解兼容。

### 典型题型
- 求通解
- 参数分类
- 同解/公共解
- 由解反推
- 证明解空间维数

### 高频易错边界
- 基础解系向量数写成 r
- 非齐次通解漏特解
- 只凭行数列数判断解的个数
- 同解只看矩阵等价

### 达标标准
任意方程组都能先用秩给出解的类型，再计算具体通解。

## L5 特征值、特征向量与相似｜优先级 A+

**本章目标：** 理解相似变换下矩阵的本质结构，并熟练处理对角化与矩阵幂。

### 知识节点
- L5.1 特征值与特征向量定义；特征多项式。
- L5.2 特征值基本关系：和为迹、积为行列式；三角矩阵对角元。
- L5.3 特征向量线性无关性；不同特征值对应特征向量线性无关。
- L5.4 相似矩阵及不变量：特征多项式、迹、行列式、秩等。
- L5.5 可对角化条件：有 n 个线性无关特征向量；几何重数等于代数重数。
- L5.6 实对称矩阵：实特征值、不同特征值特征向量正交、正交对角化。
- L5.7 矩阵多项式、矩阵幂与递推；利用最小多项式/特征关系降次。
- L5.8 参数矩阵的特征值、可对角化与相似判定。

### 核心方法
- 先利用迹、行列式、秩、已知特征向量减少特征多项式计算。
- 可对角化题按每个重特征值检查特征子空间维数；实对称矩阵直接走正交对角化。

### 典型题型
- 求谱
- 判断/构造对角化
- 矩阵幂
- 相似判定
- 实对称矩阵

### 高频易错边界
- 重特征值必不可对角化或必可对角化的错误
- 零向量当特征向量
- 相似只看特征值相同
- 正交矩阵列向量未单位化

### 达标标准
能从特征值重数与特征子空间维数准确判断可对角化，并写出 P^{-1}AP 或 P^TAP。

## L6 二次型｜优先级 A+

**本章目标：** 把二次型、对称矩阵、合同变换和正定性连成一体。

### 知识节点
- L6.1 二次型及矩阵表示；交叉项系数与对称矩阵元素的对应。
- L6.2 合同变换与变量替换；配方法化标准形。
- L6.3 正交变换化标准形：先求对称矩阵特征值与正交特征向量。
- L6.4 标准形、规范形、秩、正负惯性指数。
- L6.5 Sylvester 惯性定律。
- L6.6 正定二次型/正定矩阵：定义、特征值、顺序主子式判据。
- L6.7 半正定、负定、不定的判别与反例。
- L6.8 二次型与多元函数极值/Hessian 的联系。

### 核心方法
- 化标准形先区分题目要求：只要标准形可配方；要求正交变换则必须谱分解。
- 正定判别优先按给定信息选定义、特征值或顺序主子式，不要混用不适用条件。

### 典型题型
- 写矩阵
- 化标准形
- 求正交变换
- 正定性与参数
- 惯性指数

### 高频易错边界
- 交叉项系数忘除以 2
- 相似与合同混淆
- 一般矩阵错误使用顺序主子式判据
- 半正定只看行列式

### 达标标准
能在配方法和正交变换间正确选路；参数正定题能完整处理所有主子式或特征值条件。

## L7 线代关系网与综合题｜优先级 A+

**本章目标：** 熟练沿着‘可逆—秩—方程组—特征值—二次型’关系链推理。

### 知识节点
- L7.1 det(A)≠0 ⇔ A 可逆 ⇔ r(A)=n ⇔ Ax=0 仅零解 ⇔ 0 不是特征值。
- L7.2 r(AB) 与 r(A)、r(B)；零空间包含关系。
- L7.3 A^T A、AA^T 的秩、正定/半正定、非零特征值联系。
- L7.4 伴随矩阵、逆矩阵、特征值与秩的综合。
- L7.5 矩阵多项式与谱映射：若 λ 是 A 的特征值，则 p(λ) 是 p(A) 的特征值。
- L7.6 证明题与反例：条件是否充分、命题逆否、最小维反例。

### 核心方法
- 概念判断题先写关系链，再寻找命题缺失的条件；反例优先从 2×2 对角、Jordan、幂零矩阵中找。
- 遇到秩与乘积，既看像空间包含，也看核空间包含，常比纯公式更直观。

### 典型题型
- 关系链判断
- 综合证明
- 反例
- 参数矩阵

### 高频易错边界
- 只记单向推论不记等价条件
- 特征值相同就判相似
- AB 与 BA 的全部性质混同

### 达标标准
选择题能迅速找到缺失条件；证明题能在秩、空间、特征三种语言间切换。
