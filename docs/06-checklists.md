# 第六部分 三级知识点检查清单（v1.1 新增）

这一部分把原有二级节点继续拆成可执行、可打勾的三级任务。每一项只有在“能口述条件、能独立完成典型题、隔周回测仍正确”时才勾选。编号继续依附原节点，后续版本只增补，不轻易改号。

## 6.0 使用规则

- 第一次复习：只勾“概念能复述”；第二次复习：再勾“方法能独立使用”；真题阶段：用日期或年份替代勾号，例如“2021T18”。
- 一个三级项连续错两次，应单独建立知识卡；错题只挂到最具体的三级项，不要只写“H1 极限”。
- 状态升级证据：基础题 3 道全对只是 2 级；综合题和真题稳定、且能解释条件，才算 3—4 级。
- 优先顺序：先完成 A+/A 章节的三级项，再处理 B/C 拓展；不要因整理框架挤占做题时间。
## 6.1 高等数学三级清单

### H0 预备知识与基本语言

- [ ] H0.1-a 能快速写出幂、指数、对数、三角、反三角函数的定义域和值域，并处理复合后的额外限制。
- [ ] H0.1-b 熟悉平移、伸缩、翻折、取绝对值、取倒数后图像的变化，能据此判断零点与渐近线。
- [ ] H0.2-a 会判断复合函数的奇偶性、周期性与单调性；知道“外偶内任意”等结论的适用前提。
- [ ] H0.2-b 会由单调区间判断反函数是否存在，并正确交换反函数的定义域和值域。
- [ ] H0.3-a 能熟练使用因式分解、有理化、通分、配方与拆项，为极限和积分暴露主结构。
- [ ] H0.3-b 熟记常见三角恒等式、半角与万能代换的使用场景，不把恒等式记成近似式。
- [ ] H0.4-a 使用均值不等式、Cauchy 不等式时会同时写出变量范围和等号成立条件。
- [ ] H0.5-a 参数题先列定义域、分母、根式、对数、判别式和端点五类临界条件，再分区间讨论。
### H1 函数、极限与连续

- [ ] H1.1-a 能用 ε-N 语言解释数列极限，并理解唯一性、有界性、保号性都是“尾部性质”。
- [ ] H1.1-b 会用子列反证极限不存在；知道两个不同极限子列足以否定原数列收敛。
- [ ] H1.1-c 递推数列先猜极限，再证明有界与单调；必要时研究 x_{n+1}-x_n、x_{n+1}/x_n 或构造不动点区间。
- [ ] H1.2-a 函数极限存在须左右极限相等；无穷远极限与无穷大量的符号、方向要分开判断。
- [ ] H1.3-a 能区分高阶、低阶、同阶、等价无穷小，并用极限商定义解释关系。
- [ ] H1.3-b 等价替换通常安全用于乘除和整体复合，不在发生相消的和差中机械替换。
- [ ] H1.4-a 熟练把 1^∞、0^0、∞^0 型先取对数，转为指数与乘积极限。
- [ ] H1.4-b 掌握 sin x、tan x、arcsin x、ln(1+x)、e^x-1、1-cos x 等常用局部主项。
- [ ] H1.5-a 面对未定式能在 20 秒内从因式分解、有理化、换元、夹逼、洛必达、Taylor 中选首选路线。
- [ ] H1.5-b 使用洛必达前检查未定式、去心邻域可导、分母导数不为零以及导数商极限；出现循环时及时换方法。
- [ ] H1.5-c Taylor 只展开到“第一个不相消项”，并能根据分母阶数预判至少需要展开到几阶。
- [ ] H1.5-d 对称二阶差商 [f(x+h)+f(x-h)-2f(x)]/h² 在二阶可微条件下趋于 f″(x)；它不是一阶导数定义的直接套用。
- [ ] H1.6-a 能按左右极限与函数值把间断点分为可去、跳跃、无穷和振荡间断。
- [ ] H1.7-a 会用闭区间连续函数的有界、最值、介值、零点性质证明方程有根或取得某值。
- [ ] H1.8-a “极限存在”证明会根据结构选择夹逼、单调有界、Cauchy、子列唯一或连续映射，而不是只做形式运算。
### H2 一元函数微分学

- [ ] H2.1-a 能从定义证明可导，并准确说明可导 ⇒ 连续；连续、左右导数存在等逆命题一般不成立。
- [ ] H2.1-b 分段函数在分界点先验连续，再验左右导数；绝对值点和尖点不能只套求导公式。
- [ ] H2.2-a 熟练处理复合、反函数、隐函数、参数方程和对数求导，并保持变量与求导对象一致。
- [ ] H2.3-a 会由周期、递推、乘积和指数结构求 n 阶导数，理解 Leibniz 公式中组合数与阶数分配。
- [ ] H2.4-a Rolle 定理：连续、开区间可导、端点值相等三条件缺一不可。
- [ ] H2.4-b Lagrange 中值定理适合把函数值差转成导数；Cauchy 中值定理适合处理两个函数增量之比。
- [ ] H2.4-c 辅助函数从目标式反推：目标含 f(ξ)、f′(ξ)、ξ 的组合时，尝试把它写成某函数导数为零。
- [ ] H2.5-a 能区分 Peano 余项用于局部等价、Lagrange 余项用于误差界和不等式。
- [ ] H2.6-a 求单调区间先找定义域、驻点和不可导点；极值候选还包括区间端点。
- [ ] H2.6-b 参数极值题会找“导数零点合并、穿越定义域边界、端点改变”这些临界值。
- [ ] H2.7-a 拐点要求函数连续且凹凸性改变；f″(x)=0 只是候选条件。
- [ ] H2.8-a 渐近线按铅直、水平、斜线依次检查；斜渐近线 y=ax+b 中 a、b 用极限分别求。
- [ ] H2.9-a 根的个数统一拆成“存在性 + 至多性”；存在性多用介值，至多性多用单调或 Rolle 反证。
- [ ] H2.9-b 不等式优先设差函数，再用单调、极值、Taylor、凸性或积分，而不是盲目放缩。
- [ ] H2.10-a 曲率题会区分直角坐标、参数方程和极坐标公式，并检查弧长元素不为零。
### H3 一元函数积分学

- [ ] H3.1-a 基本积分公式不仅要会背，还要能识别复合后的“内函数导数”是否齐全。
- [ ] H3.2-a 令新元 u=φ(x) 时，定积分上下限由 x=a,b 映射为 u=φ(a),φ(b)。
- [ ] H3.2-b 令旧元 x=φ(t) 时，先找对应 t 端点，再用 dx=φ′(t)dt；有向定积分的方向由上下限和 φ′共同承担，不机械再加绝对值。
- [ ] H3.2-c 根式积分会按 √(a²-x²)、√(x²+a²)、√(x²-a²) 选择三角或双曲型代换，并能回代。
- [ ] H3.3-a 分部积分会按“反对幂三指”选 u，但以降低复杂度为最终标准；循环积分要把原积分移项求解。
- [ ] H3.4-a 真分式先部分分式，假分式先多项式除法；不可约二次因子需配导数和配方。
- [ ] H3.5-a 理解定积分的线性、区间可加、保序、绝对值估计与积分中值定理。
- [ ] H3.6-a 变上限积分求导先看上限、下限与被积函数是否含 x；多层复合要逐层链式求导。
- [ ] H3.6-b 由积分定义的函数做单调、极值、零点题时，先求导把问题还原为被积函数。
- [ ] H3.7-a 对称区间先检查奇偶；再检查 f(a-x)、f(a+x)、周期和互补关系。
- [ ] H3.8-a 反常积分必须先定位所有瑕点并拆段写极限；判敛和求值分开进行。
- [ ] H3.8-b p 型、对数修正型、指数型是比较判敛的基准；参数临界值和端点必须单独检查。
- [ ] H3.9-a 积分不等式会用保序、积分中值、Cauchy、分部积分、参数单调性和凸性。
- [ ] H3.10-a 面积先判断上下或左右关系并分段；体积根据旋转轴选择圆盘、圆环或壳层。
- [ ] H3.10-b 参数曲线和极坐标的弧长、面积公式会同时写参数范围，避免重复描绘。
- [ ] H3.11-a 物理应用先确定微元、密度和几何量，再积分；单位可作为结果合理性的检查。
### H4 常微分方程

- [ ] H4.1-a 会区分阶、线性/非线性、齐次/非齐次、通解/特解与初值问题。
- [ ] H4.2-a 可分离变量时先检查被除掉的因子是否可能为零，防止漏掉常数解。
- [ ] H4.3-a 一阶齐次型 y′=F(y/x) 用 y=ux；不要与“线性齐次方程”混淆。
- [ ] H4.4-a 一阶线性方程会用标准式 y′+P(x)y=Q(x) 和积分因子 e^{∫Pdx}。
- [ ] H4.5-a Bernoulli 方程通过 z=y^{1-n} 化为线性方程，同时检查 y=0 等特殊解。
- [ ] H4.6-a 不显含 y 的方程令 p=y′；不显含 x 的方程令 p(y)=y′并用 y″=p dp/dy。
- [ ] H4.7-a 线性方程通解结构：非齐次通解 = 齐次通解 + 任一特解。
- [ ] H4.8-a 常系数齐次方程会按实根、重根和共轭复根写齐次解。
- [ ] H4.9-a 待定系数法先由右端设型，再按与特征根重合次数乘 x^s。
- [ ] H4.10-a Euler 方程用 x=e^t 或试解 y=x^m 转为常系数结构，注意 x 的取值区间。
- [ ] H4.11-a 建模题能从守恒、变化率或牛顿定律建立方程，并用初值确定常数。
- [ ] H4.12-a 解出后代回原方程、初值与定义域，检查对数、分母和平方根限制。
### H5 向量代数与空间解析几何

- [ ] H5.1-a 数量积处理夹角和投影，向量积处理法向量和面积，混合积处理体积与共面。
- [ ] H5.1-b 向量积交换顺序会变号；右手规则要与曲面方向、Stokes 边界方向统一。
- [ ] H5.2-a 平面方程能在点法式、一般式和截距式之间转换，并从系数直接读法向量。
- [ ] H5.3-a 直线能在参数式、对称式、两平面交线式之间转换，并正确写方向向量。
- [ ] H5.4-a 会求点到平面距离、点到直线距离，以及利用投影求夹角和最短距离。
- [ ] H5.5-a 能用截面法识别柱面、锥面、旋转曲面和常见二次曲面。
- [ ] H5.6-a 空间曲线由两个曲面联立时，会消元求投影曲线并补充投影范围。
- [ ] H5.7-a 空间区域先画关键截面，再找上下表面和投影边界，不凭立体想象直接写积分限。
- [ ] H5.8-a 选择直角、柱面、球面坐标时同时比较区域与被积函数，避免“见圆就极坐标”。
- [ ] H5.9-a 能把几何关系转成法向量、方向向量、距离或交线方程，为多元积分服务。
### H6 多元函数微分学

- [ ] H6.1-a 二重极限用不同路径只能否定，不能凭有限条路径相同证明存在。
- [ ] H6.1-b 证明二重极限常用极坐标估计、夹逼、不等式或把表达式控制为 r 的函数。
- [ ] H6.2-a 准确掌握“可微 ⇒ 连续 ⇒? 偏导存在”的关系：可微可推出偏导存在和连续，但偏导存在不推出可微。
- [ ] H6.2-b 可微性用增量 Δz=AΔx+BΔy+o(ρ) 或拆分估计验证。
- [ ] H6.3-a 复合函数求导先画依赖树；二阶偏导要把每条依赖路径都求一次。
- [ ] H6.4-a 隐函数求导前检查相应偏导或 Jacobian 不为零；结果要标明在哪个点成立。
- [ ] H6.5-a 方向导数沿单位向量计算；梯度给出最大增长方向和最大方向导数。
- [ ] H6.6-a 曲面 F(x,y,z)=0 的法向量是 ∇F；空间曲线交线切向量可由两个法向量叉乘。
- [ ] H6.7-a 无条件极值先找驻点，再用 Hessian；判别式为零时需换高阶项、配方或沿路径分析。
- [ ] H6.8-a Lagrange 乘数法需要约束梯度不全为零；多约束时每个约束配一个乘子。
- [ ] H6.9-a 闭区域最值必须比较内部驻点、各段边界和角点，不能只做 Lagrange。
- [ ] H6.10-a 多元 Taylor 的二次项与 Hessian 二次型相连，可用于局部极值和误差估计。
- [ ] H6.11-a 全微分形式与链式法则能互相验证；注意 dz 与偏导数并非同一对象。
- [ ] H6.12-a 参数导致极值类型变化时，重点检查 Hessian 退化、驻点合并和边界穿越。
### H7 重积分

- [ ] H7.1-a 理解二重/三重积分是区域上的累加，积分限必须来自区域而非被积函数。
- [ ] H7.2-a 直角坐标写 X 型或 Y 型区域；交换次序时重新切片，必要时分区。
- [ ] H7.2-b 能从已有累次积分反画区域，并识别上下限中隐藏的交点。
- [ ] H7.3-a 极坐标正确写 x=r cosθ、y=r sinθ、dA=r drdθ；角度范围防止重复覆盖。
- [ ] H7.4-a 利用奇偶性前同时检查区域关于相应轴或原点对称；轮换对称要求区域与被积函数整体不变。
- [ ] H7.5-a 一般换元使用 dA=|∂(x,y)/∂(u,v)|dudv；若题目给的是 ∂(u,v)/∂(x,y)，需要取倒数并确认非零。
- [ ] H7.5-b 线性变换、椭圆化圆时同时变换区域、被积函数和 Jacobian，三者缺一不可。
- [ ] H7.6-a 三重积分会在“先一后二”和“先二后一”之间选择；先积分的变量要有清晰上下界。
- [ ] H7.7-a 柱面坐标体元为 r drdθdz；球面坐标体元为 ρ² sinφ dρdφdθ，并明确 φ、θ 的定义。
- [ ] H7.8-a 三维对称与变量轮换可用于求 x²、y²、z² 等积分，但需检查区域是否完全对称。
- [ ] H7.9-a 质量、质心、转动惯量题先写密度和微元；质心是一次矩除以总质量。
- [ ] H7.10-a 反常重积分先识别无界区域或奇点，再用截断区域极限或比较判敛。
- [ ] H7.11-a 复杂区域优先分区或换元，不把一个非单值边界硬塞进单个积分。
- [ ] H7.12-a 计算后用量纲、正负性、对称性和粗略上下界检查结果。
### H8 曲线积分与曲面积分

- [ ] H8.1-a 第一类曲线积分与方向无关，参数化后使用 ds=|r′(t)|dt。
- [ ] H8.2-a 第二类曲线积分与方向有关，参数化后将 dx,dy,dz 全部替换为参数微分。
- [ ] H8.3-a Green 公式要求平面区域及边界满足相应光滑性，边界取正向；有洞区域要处理内边界方向。
- [ ] H8.3-b 面积公式可由 Green 选择 P,Q 得到，但符号取决于边界方向。
- [ ] H8.4-a 路径无关需同时检查偏导关系与区域的单连通性；有奇点或孔洞时不能只看 P_y=Q_x。
- [ ] H8.4-b 求势函数可先对一个变量积分，再用另一个偏导确定“积分常数函数”。
- [ ] H8.5-a 第一类曲面积分无方向；投影法要乘面积伸缩因子，参数法用 |r_u×r_v|。
- [ ] H8.6-a 第二类曲面积分先确定法向侧，再决定投影符号；上侧/下侧、外侧/内侧必须画图。
- [ ] H8.7-a Gauss 公式只直接用于封闭曲面且取外侧；开曲面常先补面，奇点需挖洞。
- [ ] H8.8-a Stokes 公式中曲面法向与边界方向遵循右手规则；可换成同边界的更简单曲面。
- [ ] H8.9-a 四类积分转换时先判断目标维数：Green 把边界变区域，Gauss 把曲面变体积，Stokes 把边界变曲面。
- [ ] H8.10-a 梯度、散度、旋度分别对应势、源汇和局部旋转；会从计算结果判断结构。
- [ ] H8.11-a 所谓轮换/旋转对称不能机械换字母：第二类积分还要求向量场分量、微分形式与方向一起按同一变换变化。
- [ ] H8.12-a 对称消项时检查法向量或切向量是否在对称变换下变号，第一类与第二类结论可能不同。
- [ ] H8.13-a 定理条件不满足时优先选择直接参数化、补线补面或挖小洞，而不是强套公式。
### H9 无穷级数

- [ ] H9.1-a 判敛第一步检查一般项是否趋于零；不趋零可立即判发散。
- [ ] H9.2-a 正项级数会按结构选比较、极限比较、比值、根值或积分判别。
- [ ] H9.2-b 含 n!、a^n 常优先比值；含 n 次根常优先根值；幂与对数常与 p 级数比较。
- [ ] H9.3-a 交错级数使用 Leibniz 时需验证绝对值单调趋零，并会用首个舍去项估计余项。
- [ ] H9.4-a 能区分绝对收敛与条件收敛；拆项或合并前检查是否保持合法性。
- [ ] H9.5-a 幂级数先求收敛半径，再把两个端点分别代回原级数判定。
- [ ] H9.6-a 在收敛区间内部可逐项求导、积分；新级数半径不变但端点需重新判断。
- [ ] H9.7-a 求和函数常从几何级数出发，经积分、求导、乘 x^k、变量替换构造。
- [ ] H9.8-a 熟记 e^x、sin x、cos x、ln(1+x)、(1+x)^α 的 Maclaurin 展开与收敛范围。
- [ ] H9.9-a Fourier 系数先利用奇偶性简化；周期延拓与奇偶延拓要区分。
- [ ] H9.9-b 在跳跃点 Fourier 级数收敛到左右极限平均值，不一定等于原函数点值。
- [ ] H9.10-a 级数与积分、极限交换只在题目允许的框架内进行；考研常通过幂级数合法区间实现。
- [ ] H9.11-a 含参数级数找临界值时同时检查一般项、内部判别和边界点。
### H10 高数综合连接层

- [ ] H10.1-a 看到变上限积分先求导；看到导数定义型极限先检查能否转为 Taylor 或中值定理。
- [ ] H10.2-a 单调、极值、凹凸常用于根数、不等式和积分估值，能写出“性质 → 结论”的信息流。
- [ ] H10.3-a 定积分定义的函数可导出微分方程；微分方程解也可通过积分表达验证。
- [ ] H10.4-a 多元极值的 Hessian 本质是二次型，可调用线代的正定性判断。
- [ ] H10.5-a 空间几何决定积分区域与方向；三重积分、曲面积分之间可由 Gauss 连接。
- [ ] H10.6-a Green、Gauss、Stokes 都是“边界积分与内部微分量”的转换，先辨维数再选定理。
- [ ] H10.7-a 参数综合题先找临界值：等号成立、根合并、端点可积、Hessian 退化、特征根重合。
- [ ] H10.8-a 综合题开算前用一句话写路线，例如“积分定义函数 → 求导 → 根数”，防止局部计算失控。
## 6.2 线性代数三级清单

### L0 全局语言：秩、空间与变换

- [ ] L0.1-a 每题先写矩阵尺寸，区分矩阵、向量组、方程组和线性变换正在回答的问题。
- [ ] L0.1-b 列空间描述 Ax 能到达的向量，零空间描述 Ax=0 的自由方向，行空间与约束相关。
- [ ] L0.2-a det(A) 判断方阵可逆，r(A) 判断独立约束数，特征值描述相似结构，惯性指数描述合同结构。
- [ ] L0.3-a 初等行/列变换保持秩但不保持特征值；相似保持特征结构；合同保持惯性指数。
- [ ] L0.4-a 熟练使用 dim N(A)=n-r(A)，并把自由变量个数与基础解系向量数对应。
- [ ] L0.5-a 左乘矩阵改变行组合，右乘矩阵改变列组合；矩阵方程必须保持乘法顺序。
- [ ] L0.6-a 线代证明优先在“秩、零空间、列空间、特征子空间、正定性”中寻找不变量。
- [ ] L0.7-a 会用反例检验貌似对称的逆命题，例如 AB=0 不推出 A=0 或 B=0。
### L1 行列式

- [ ] L1.1-a 理解行列式是多线性交替函数，计算时主要使用性质和展开。
- [ ] L1.2-a 交换两行变号，某行乘 k 行列式乘 k，某行加另一行倍数不变。
- [ ] L1.3-a 会按含零最多的一行/列展开，正确处理代数余子式符号 (-1)^{i+j}。
- [ ] L1.3-b 熟悉某行元素与另一行代数余子式乘积和为零的结论。
- [ ] L1.4-a 能识别三角、Vandermonde、箭形、循环和递推行列式，并通过造零或差分降阶。
- [ ] L1.5-a 分块行列式使用 Schur 补时明确哪一块可逆，不能把标量公式无条件套到矩阵块。
- [ ] L1.6-a 熟练使用 det(AB)、det(A^T)、det(A^{-1})、det(kA)、det(A*)。
- [ ] L1.7-a 参数行列式先找行列相关或共同因子，再确定零点重数。
- [ ] L1.8-a Cramer 法则只适用于方阵且 det(A)≠0；更重要的结论是唯一解与可逆等价。
- [ ] L1.9-a 计算后用维数、次数和特殊参数代入检查答案。
### L2 矩阵

- [ ] L2.1-a 乘法前检查内维匹配；转置乘积顺序反转：(AB)^T=B^TA^T。
- [ ] L2.2-a 方阵可逆等价于满秩、行列式非零、零不是特征值、齐次方程只有零解。
- [ ] L2.2-b 求逆会根据结构选伴随、增广初等变换、分块或因式分解，不机械套公式。
- [ ] L2.3-a 明白左乘初等矩阵做行变换，右乘做列变换，并能写出变换矩阵。
- [ ] L2.4-a 秩可由阶梯形读出，也可用非零子式证明下界；“存在 r 阶非零子式”是关键。
- [ ] L2.4-b 熟练使用 r(AB)≤min{r(A),r(B)} 与 Sylvester 下界，并知道何时只能给界不能给等号。
- [ ] L2.5-a 分块矩阵运算先检查块尺寸；上三角分块矩阵的行列式等于对角块行列式之积。
- [ ] L2.6-a 解 AX=B 时列视角是多个同系数方程组；解 XA=B 时可转置或按行处理。
- [ ] L2.6-b AXB=C 不能随意“约去”A、B；只有可逆时才能按正确顺序左右乘逆。
- [ ] L2.7-a 对称、反对称、正交、幂等、幂零矩阵的定义和常见谱性质会辨析。
- [ ] L2.8-a 伴随矩阵秩按 r(A)=n、n-1、≤n-2 分类；注意 n=1 的特殊情形。
- [ ] L2.9-a 矩阵等式题会用取秩、取迹、取行列式、乘特征向量等手段提取标量信息。
### L3 向量组与线性空间

- [ ] L3.1-a “β 能由 α 组表示”转为方程 Ax=β；“相互表示”对应向量组等价。
- [ ] L3.2-a 线性相关等价于齐次方程存在非零解；无关等价于列满秩。
- [ ] L3.2-b 添加向量后无关性可能丢失，删除向量后相关性可能丢失；会判断单向保持关系。
- [ ] L3.3-a 极大无关组从阶梯形主元列选取时，应回到原矩阵的对应列。
- [ ] L3.4-a 行秩等于列秩；行空间与列空间维数都等于矩阵秩，但它们所在空间可能不同。
- [ ] L3.5-a 基是线性无关且生成全空间；坐标由基矩阵的线性方程求得。
- [ ] L3.5-b 过渡矩阵方向通过“新基 = 旧基 × P”固定，坐标变换使用 P^{-1}，不靠死记。
- [ ] L3.6-a Schmidt 正交化每一步减去对前面所有正交向量的投影，最后再单位化。
- [ ] L3.7-a 子空间和与交满足 dim(U+V)=dimU+dimV-dim(U∩V)。
- [ ] L3.8-a 会用齐次方程表示子空间，用基础解系求基，并在交空间问题中联立约束。
### L4 线性方程组

- [ ] L4.1-a 齐次方程 Ax=0 必有零解；存在非零解当且仅当 r(A)<n。
- [ ] L4.2-a 基础解系向量数是 n-r(A)，通解由自由变量线性组合给出。
- [ ] L4.3-a 非齐次有解当且仅当 r(A)=r(A|b)；唯一解还需该秩等于未知量个数 n。
- [ ] L4.4-a 非齐次通解 = 一个特解 + 对应齐次通解；两个特解之差必为齐次解。
- [ ] L4.5-a 参数方程组通过最简阶梯形找秩变化点，参数值分类时避免除以可能为零的式子。
- [ ] L4.6-a 两个齐次方程组同解等价于零空间相同，也等价于行空间相同。
- [ ] L4.6-b 两个非齐次方程组也有“同解”概念：最稳方法是比较增广矩阵最简形；或找公共特解并比较对应齐次零空间。
- [ ] L4.6-c 公共解问题把两个方程组纵向合并；解集包含问题比较约束是否可由另一组线性表示。
- [ ] L4.7-a 多右端矩阵方程 AX=B 按列同时消元，存在性由 B 的每一列是否属于 A 的列空间决定。
- [ ] L4.8-a 由解反推系数时利用“解之差属于零空间”“所有解构成仿射子空间”。
- [ ] L4.9-a 同解不能只比较秩；相同秩只说明维数可能相同，不说明方向和位置相同。
- [ ] L4.10-a 解题结束检查自由变量数、基础解系个数和通解参数个数是否一致。
### L5 特征值、特征向量与相似

- [ ] L5.1-a 特征向量必须非零；求特征值先解 det(λI-A)=0，再求各 λ 的零空间。
- [ ] L5.2-a 特征值之和等于迹、乘积等于行列式；三角矩阵特征值为对角元。
- [ ] L5.2-b A 可逆时 A^{-1} 特征值为 1/λ；f(A) 对同一特征向量的特征值为 f(λ)。
- [ ] L5.3-a 不同特征值对应特征向量线性无关；同一特征值的特征向量需在其特征子空间内选基。
- [ ] L5.4-a 相似保持特征多项式、迹、行列式、秩等，但反向“这些量相同 ⇒ 相似”通常不成立。
- [ ] L5.5-a 可对角化当且仅当有 n 个线性无关特征向量；对每个重根检查几何重数是否等于代数重数。
- [ ] L5.5-b n 个互异特征值足以可对角化，但不是必要条件。
- [ ] L5.6-a 实对称矩阵必可正交对角化，且不同特征值的特征向量正交。
- [ ] L5.7-a 求 A^n 优先用对角化、低阶多项式关系或递推，不直接连乘。
- [ ] L5.8-a 参数矩阵的可对角化临界通常出现在特征根重合处，但重合后仍需检查特征子空间维数。
- [ ] L5.9-a A 与 A^T 特征多项式相同；AB 与 BA 的非零特征值结构相关，但尺寸和零特征值需谨慎。
- [ ] L5.10-a 伴随矩阵 A* 在 A 可逆时等于 det(A)A^{-1}，可据此转化特征值。
- [ ] L5.11-a 构造 P 时按列放对应特征向量，并确认 AP=PΛ，而不是把顺序写反。
### L6 二次型

- [ ] L6.1-a 二次型只由对称部分决定；交叉项 2a_{ij}x_ix_j 对应矩阵元素 a_{ij}=a_{ji}。
- [ ] L6.2-a 变量代换 x=Cy 后矩阵变为 C^TAC，这是合同变换，不是相似变换。
- [ ] L6.3-a 化标准形可用配方法、初等合同变换或正交变换；三者目的相同但保留信息不同。
- [ ] L6.4-a 规范形只保留 ±1 与 0；正负惯性指数在可逆合同变换下不变。
- [ ] L6.5-a Sylvester 惯性定理用于判断两个实对称矩阵是否合同。
- [ ] L6.6-a 正定等价于所有非零 x 有 x^TAx>0；实对称矩阵还等价于特征值全正。
- [ ] L6.6-b 顺序主子式全正是实对称矩阵正定的判据；不要误用到非对称矩阵。
- [ ] L6.7-a 半正定时顺序主子式条件不够直接套用，常用特征值或所有主子式判断。
- [ ] L6.8-a 参数正定题找主子式或特征值的零点作为临界值，并检查开闭区间。
- [ ] L6.9-a 正交对角化既给标准形也给坐标变换，特征向量必须单位正交。
- [ ] L6.10-a 多元函数 Hessian 的正定/负定与局部极值相连，理解其与 H6 的跨模块关系。
### L7 线代关系网与综合题

- [ ] L7.1-a 可逆关系链：det≠0 ⇔ r=n ⇔ Ax=0 仅零解 ⇔ 0 非特征值。
- [ ] L7.2-a 秩关系链：列空间维数、行空间维数、主元数相同；零空间维数为 n-r。
- [ ] L7.3-a 方程组与特征值结合时，(A-λI)x=0 的非零解就是特征向量问题。
- [ ] L7.4-a 实对称矩阵把相似与合同连接起来：正交对角化既展示特征值，也展示二次型符号。
- [ ] L7.5-a 综合证明会从目标选择取秩、取行列式、取迹、作用于特征向量或比较零空间。
- [ ] L7.6-a 参数题先找秩下降、特征根重合、主子式为零等临界点，再分类。
- [ ] L7.7-a 概念选择题用最小维度反例检验逆命题，2×2 矩阵通常足够。
- [ ] L7.8-a 最终答案用尺寸、维数、秩界、迹和行列式做交叉检查。
## 6.3 概率论与数理统计三级清单

### P1 随机事件与概率

- [ ] P1.1-a 能用集合语言表示和、积、差、对立与互斥，并正确使用 De Morgan 公式。
- [ ] P1.2-a 古典概型先确认等可能；几何概型用区域测度之比并明确样本空间。
- [ ] P1.3-a 条件概率 P(A|B) 的分母 P(B)>0；乘法公式按事件发生顺序展开。
- [ ] P1.4-a 全概率公式先构造完备事件组，Bayes 公式用于由结果反推原因。
- [ ] P1.5-a 独立与互斥不同：非零概率互斥事件通常不独立。
- [ ] P1.5-b 两两独立不必相互独立；多事件独立需检查所有子集交事件。
- [ ] P1.6-a 重复独立试验识别试验次数 n、单次成功概率 p 和成功次数。
- [ ] P1.7-a 递推概率题先定义状态与目标事件，用“第一步分析”列方程。
- [ ] P1.8-a 至少一次、恰好一次、首次发生等措辞优先用对立事件或分步乘法。
- [ ] P1.9-a 结果必须在 [0,1] 内，并用极端参数或对称性检查。
### P2 一维随机变量及其分布

- [ ] P2.1-a 分布函数满足单调不减、右连续、两端极限 0 和 1；跳跃大小是点概率。
- [ ] P2.2-a 离散型由概率质量函数给出，所有概率非负且和为 1。
- [ ] P2.2-b 熟练识别 0-1、二项、Poisson、几何分布的参数、期望和方差。
- [ ] P2.3-a 连续型概率由密度积分得到，单点概率为 0；密度值本身可以大于 1。
- [ ] P2.3-b 熟练识别均匀、指数、正态分布，并进行标准化。
- [ ] P2.4-a 由密度求分布函数时按区间积分并保证连续；由分布函数求密度要注意不可导点和跳跃。
- [ ] P2.5-a Y=g(X) 的分布优先用分布函数法；单调变换可用反函数与导数公式。
- [ ] P2.5-b 非单调变换需把所有原像分支的密度贡献相加，并处理值域。
- [ ] P2.6-a 混合型随机变量同时含点质量和连续密度，分布函数会既跳跃又连续增长。
- [ ] P2.7-a 指数分布和几何分布的无记忆性要分别理解连续与离散版本。
- [ ] P2.8-a 参数密度先用积分为 1 求参数，再检查非负性与定义域。
- [ ] P2.9-a 概率计算优先画数轴和事件区间，避免补集、开闭端点和标准化方向出错。
### P3 多维随机变量及联合分布

- [ ] P3.1-a 联合分布函数要满足二维单调性、右连续和边界条件；矩形概率用四项差。
- [ ] P3.2-a 离散联合分布表的各项非负、总和为 1；边缘分布由行和或列和得到。
- [ ] P3.3-a 连续联合密度在区域外为 0，总积分为 1；概率是区域上的二重积分。
- [ ] P3.4-a 条件分布等于联合量除以边缘量，分母为零处没有意义。
- [ ] P3.5-a 独立的判定是联合分布可分解为边缘分布乘积，并同时检查支撑区域是否为直积。
- [ ] P3.6-a 变量变换会画原区域、求逆变换并乘绝对 Jacobian；多对一映射要分支求和。
- [ ] P3.7-a Z=X+Y 的密度会用卷积，并根据支撑区域确定积分上下限。
- [ ] P3.8-a max(X,Y) 与 min(X,Y) 常用分布函数法；独立时 P(max≤z)=F_X(z)F_Y(z)。
- [ ] P3.9-a i.i.d. 样本最大值分布 F_{X_(n)}(x)=F(x)^n，最小值分布 F_{X_(1)}(x)=1-[1-F(x)]^n。
- [ ] P3.9-b 一般第 k 个次序统计量会用“恰有 k-1 个不超过 x”的组合结构理解密度公式。
- [ ] P3.10-a 和、差、积、商的分布优先选最容易描述事件区域的方法，不机械套 Jacobian。
- [ ] P3.11-a 二维正态中“不相关 ⇔ 独立”只对联合正态成立，不能推广到任意分布。
- [ ] P3.12-a 对称区域与交换 X,Y 可简化积分，但需检查联合密度是否也对称。
- [ ] P3.13-a 画支撑区域是二维分布题的第一步，边缘积分限必须从图上读取。
### P4 随机变量的数字特征

- [ ] P4.1-a 期望是加权平均，存在性需检查绝对可积或级数收敛；线性性质不要求独立。
- [ ] P4.2-a E[g(X)] 可直接对原分布积分/求和，不必先求 Y=g(X) 的分布。
- [ ] P4.3-a 方差会用 D(X)=E(X²)-[E(X)]²，并理解平移不变、倍乘平方。
- [ ] P4.4-a 协方差与相关系数会计算并解释；相关系数绝对值不超过 1。
- [ ] P4.5-a 独立推出不相关（若二阶矩存在），不相关一般不推出独立。
- [ ] P4.6-a D(X+Y)=D(X)+D(Y)+2Cov(X,Y)，只有独立或不相关时交叉项为零。
- [ ] P4.7-a 标准化后均值为 0、方差为 1；线性组合的均值和方差会根据协方差展开。
- [ ] P4.8-a 最大最小值的期望可先求分布，也可用 E[max]+E[min]=E[X]+E[Y] 等恒等式。
- [ ] P4.9-a 参数估计前会计算样本均值、样本方差的期望与方差，为无偏性服务。
- [ ] P4.10-a 最后检查方差非负、相关系数范围和量纲。
### P5 大数定律与中心极限定理

- [ ] P5.1-a Chebyshev 不等式把方差界转成偏离均值的概率界，适合信息不足时估计。
- [ ] P5.2-a 大数定律描述样本平均趋近总体均值；中心极限定理描述标准化和的近似分布。
- [ ] P5.3-a Bernoulli 大数定律用于频率趋近概率，Khintchine 大数定律用于 i.i.d. 有有限期望。
- [ ] P5.4-a de Moivre-Laplace 是二项分布的正态近似，Lindeberg-Levy 用于 i.i.d. 和。
- [ ] P5.5-a 标准化时准确写均值 nμ、方差 nσ²，或样本均值方差 σ²/n。
- [ ] P5.6-a 二项正态近似会根据题目习惯考虑连续性修正，并明确是近似。
- [ ] P5.7-a “至少/至多”转成标准正态概率时注意不等号方向和临界点。
- [ ] P5.8-a 分辨题目是在问极限概率、近似概率还是依概率收敛，不能混用结论。
- [ ] P5.9-a 结果用 n 增大时的趋势和概率范围检查。
### P6 数理统计基本概念与抽样分布

- [ ] P6.1-a 总体是随机变量的分布，样本是 i.i.d. 随机变量组，样本观测值是具体数。
- [ ] P6.2-a 统计量不能含未知参数；样本均值与样本方差都是统计量。
- [ ] P6.3-a 样本方差采用 1/(n-1) 是为了无偏，区分 S² 与使用 1/n 的样本二阶中心矩。
- [ ] P6.4-a χ² 分布来自独立标准正态平方和，自由度等于独立项个数。
- [ ] P6.5-a t 分布是标准正态除以独立 χ²/自由度的平方根，F 分布是两个独立 χ²/自由度之比。
- [ ] P6.6-a 正态总体样本中 X̄~N(μ,σ²/n)。
- [ ] P6.7-a 正态样本的 X̄ 与 S² 独立，且 (n-1)S²/σ²~χ²(n-1)。
- [ ] P6.8-a σ 未知时 (X̄-μ)/(S/√n)~t(n-1)；这是单总体 t 推断的核心。
- [ ] P6.9-a 两个独立正态样本的均值差和方差比会根据已知/未知方差选正态、t 或 F 枢轴量。
- [ ] P6.10-a Cochran 定理可作为“平方和分解、自由度相加、独立性”的结构来源。
- [ ] P6.11-a 查分位点前确认左尾/右尾定义；利用 t 对称性和 F 倒数关系避免符号错误。
- [ ] P6.12-a 抽样分布题先写总体条件（是否正态）、样本独立性和自由度，再套结论。
### P7 参数估计

- [ ] P7.1-a 点估计量是样本的函数，估计值是代入观测数据后的数值。
- [ ] P7.2-a 矩估计按“样本矩 = 总体矩”列方程，参数个数决定所需矩方程数。
- [ ] P7.3-a 最大似然先写联合似然，必要时取对数；参数支持集依赖样本时要特别处理边界。
- [ ] P7.4-a 求极值除求导外还要检查参数空间边界和单调性，不能只解驻点。
- [ ] P7.5-a 无偏性通过 E(θ̂)=θ 判断；渐近无偏不等于无偏。
- [ ] P7.6-a 在无偏估计量中比较方差谈有效性；一致性描述样本量增大时依概率趋于真值。
- [ ] P7.7-a 正态均值区间：σ 已知用 Z，σ 未知用 t。
- [ ] P7.8-a 正态方差区间使用 χ² 枢轴量，区间端点因倒数关系要特别注意顺序。
- [ ] P7.9-a 单侧置信区间与双侧区间的分位点不同，先根据问题方向确定尾部。
- [ ] P7.10-a 估计函数 g(θ) 时可先估 θ 再变换，但无偏性未必随非线性变换保留。
- [ ] P7.11-a 区间结果检查置信度越高通常越宽、样本量越大通常越窄。
### P8 假设检验

- [ ] P8.1-a 明确原假设 H0、备择 H1、显著性水平 α、统计量和拒绝域五要素。
- [ ] P8.2-a 双侧检验对应“≠”，右侧对应“>”，左侧对应“<”；方向由备择假设决定。
- [ ] P8.3-a 第一类错误是在 H0 真时拒绝 H0，其概率受 α 控制；第二类错误与具体备择参数有关。
- [ ] P8.4-a 检验功效为 1-β；固定样本量时压低两类错误存在权衡。
- [ ] P8.5-a 单正态总体均值检验根据 σ 已知/未知选 Z/t；方差检验用 χ²。
- [ ] P8.6-a 两正态总体均值差检验要先辨方差已知、未知但相等、未知且不作相等假设等情形。
- [ ] P8.7-a 方差比检验用 F 统计量，自由度和分子分母顺序决定临界值。
- [ ] P8.8-a 临界值法与 p 值法结论一致；p 值越小，反对 H0 的证据越强。
- [ ] P8.9-a 置信区间与双侧检验具有对偶性：原假设参数落在区间内通常不拒绝。
- [ ] P8.10-a “不拒绝 H0”不等于“证明 H0 为真”，表达要严谨。
- [ ] P8.11-a 完成检验后用题目语境写结论，不只写统计量落在某区间。
### P9 概率统计综合连接层

- [ ] P9.1-a 联合分布 → 边缘/条件 → 数字特征是一条完整信息链。
- [ ] P9.2-a 随机变量变换既可求分布，也可直接求期望；按目标选择代价更低的路线。
- [ ] P9.3-a 次序统计量把“一维分布 + 二项计数”连接起来，最大最小先用分布函数。
- [ ] P9.4-a 正态总体 + 抽样分布是估计和检验的前置，先辨总体条件再选枢轴量。
- [ ] P9.5-a 估计与检验共享 Z、t、χ²、F 四类标准化统计量。
- [ ] P9.6-a 参数题先由归一化求参数，再求分布、矩或估计量，保持顺序。
- [ ] P9.7-a 综合题画出“概率模型 → 分布 → 数字特征 → 抽样 → 推断”的层级。
- [ ] P9.8-a 用概率范围、方差非负、自由度和样本量趋势做最终检查。

## 6.4 跨模块方法库三级清单

这一组清单不再重复某一章的公式，而是检查你能否把方法迁移到陌生题。每一项都要落到一道具体题上说清“为什么选、何时停、怎样回验”，只会复述方法名称还不算完成。

### M1 定义优先与条件检查

- [ ] M1.1-a 面对极限、可微、独立或正定等判断，能先写出带完整量词的原始定义，再说明所用等价判据为什么在本题成立。
- [ ] M1.2-a 每次调用洛必达、Taylor、Green/Gauss/Stokes、Schur 补或 t/χ²/F 前，能逐项写出对象、区域、光滑性、可逆性、独立性与自由度条件。
- [ ] M1.3-a 得到答案后能独立检查定义域、分母、方向、端点、参数范围和自由度，并在检查失败时定位到第一处非法变形。

### M2 对称性、奇偶性与轮换

- [ ] M2.1-a 一元定积分先写出区间映射，再同时检查被积函数、微元与上下限如何变化，不只凭“看起来奇偶”下结论。
- [ ] M2.2-a 二重或三重积分使用对称与轮换前，能验证区域在变换下不变，并追踪被积函数和 Jacobian 的同号、变号或置换关系。
- [ ] M2.3-a 曲线或曲面积分做对称变换时，能同步判断切向、法向和边界方向，区分无方向的第一类与有方向的第二类积分。
- [ ] M2.4-a 联合分布交换 X、Y 后，能由联合分布或密度的对称性推出同分布结论，同时明确这本身不能推出独立。
- [ ] M2.5-a 对称矩阵题能把“对称”落实为实特征值、正交特征向量与正交对角化，并说明这些结论不能直接移给一般矩阵。

### M3 参数与临界值分类

- [ ] M3.1-a 含参题能系统收集分母为零、判别式为零、阶数改变、秩下降、端点敛散和 Hessian 退化等临界来源，不凭试算漏点。
- [ ] M3.2-a 能在临界值分出的每个开区间取样判断，并把每个临界点代回原问题单独复核，保证分类互斥且穷尽。
- [ ] M3.3-a 分类前先写参数的原始允许范围；参数改变定义域、支撑集或积分区域时，能先更新对象再继续计算。

### M4 存在性、唯一性与个数

- [ ] M4.1-a 方程根问题能把“至少一个”和“至多一个”拆开：前者寻找介值或构造，后者寻找单调性或 Rolle 反证。
- [ ] M4.2-a 判断原函数或势函数存在时，能同时检查局部偏导关系与定义域的连通、单连通和奇点，而不把局部条件误当全局结论。
- [ ] M4.3-a 方程组问题能用系数矩阵与增广矩阵的秩判断有解性，再用 n-r(A) 说明解空间维数和唯一性。
- [ ] M4.4-a 估计或检验问题能说清参数空间、解或区间的存在范围，以及结论是否唯一；遇到边界时会回到原似然或枢轴量检查。

### M5 变换与降维

- [ ] M5.1-a 一元积分或微分方程代换前能说明新变量为何降低复杂度，代换后同步变更微分与端点，并检查被除因子和漏解。
- [ ] M5.2-a 使用极、柱、球坐标时能从区域决定角度与径向范围，写对 Jacobian，并检查是否重复覆盖或漏掉边界。
- [ ] M5.3-a 随机变量变换能先画值域和原像；一对一时用反函数，多对一时分支求和，标准化时同步变换均值和尺度。
- [ ] M5.4-a 能区分初等变换、相似变换与合同变换各自保持的量，并根据目标是秩、谱还是惯性指数选择变换。
- [ ] M5.5-a 使用 Green、Gauss、Stokes 降维或升维前，能先辨边界与内部的维数关系，再核对光滑性、封闭性、方向和奇点。

### M6 证明题模板库

- [ ] M6.1-a 看到含 f(ξ)、f′(ξ) 或端点差的结论，能从目标反推辅助函数，并逐项核对中值定理的连续、可导和端点条件。
- [ ] M6.2-a 不等式证明能先设差函数，再根据导数符号、极值或凸性确定路线，并把等号条件与定义域一并写清。
- [ ] M6.3-a 根数上界能先假设存在过多不同根，再连续使用 Rolle 导出矛盾；能说明每次使用所需的区间与可导条件。
- [ ] M6.4-a 线代证明能把结论改写为空间包含、零空间或维数关系，并用秩—零度定理检查推理方向。
- [ ] M6.5-a 证明无偏、独立或正定时能从各自定义出发，分别核对期望存在、联合分解或“任意非零向量”等关键量词。
- [ ] M6.6-a 否定错误命题时能优先构造满足全部前提的最小维反例，并明确指出反例击破的是结论中的哪一个量词或逆向推断。

### M7 计算稳定性与书写

- [ ] M7.1-a 全程能稳定管理负号、绝对值、方向、上下限和矩阵乘法顺序；发生变量替换时把符号变化写在同一行。
- [ ] M7.2-a 对重复出现的复杂积分、参数组合、特征多项式或联合密度区域主动命名，并保持定义在后续步骤中不漂移。
- [ ] M7.3-a 交卷前能用量纲、符号、范围、概率区间、方差非负和秩界至少做一次独立回验，而不是重算原过程。
- [ ] M7.4-a 解答题按“判型—条件—关键等式—结论”组织采分点，定理名称和最终语境结论不只留在草稿里。
