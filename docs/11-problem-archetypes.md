# 第十一部分 典型真题母题索引（v1.2 新增）

本部分不复制整道真题题面，也不在未核验时硬填年份题号，而是把历年真题反复出现的“命题任务”压缩为稳定母题。做完真题后，只需在题号旁挂接母题 ID，便能统计自己究竟反复卡在哪一种结构。

## 11.0 挂接规则

- 记录格式建议：“年份-题号｜母题 ID｜节点｜用时｜错因标签｜回测日期”，例如“20XX-18｜Q-H23｜H8.3｜14min｜T｜+7d”。
- 一道综合题允许挂 2—4 个母题 ID，但必须指定一个“主失分母题”；否则统计结果会失去诊断价值。
- 只有亲自核对过试卷和答案后才写年份、题号；本框架只保存索引与方法，不大段复制受版权保护的题面。
