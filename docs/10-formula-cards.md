# 第十部分 公式与结论速查系统（v1.2 新增）

这一部分不是把公式堆在一起，而是给每条公式绑定“节点、触发条件、记忆方式和失效边界”。先根据题目结构调用公式，再检查条件；能从定义在 30 秒内推出的结论不必死背。

## 10.0 使用规则与符号

- 记忆标签：[背] 需要直接提取；[推] 应能由定义或标准公式快速推出；[慎] 条件敏感，使用前必须逐项检查；[拓] 超出最小主线但可处理陌生变式。
- 本表中的“~”均指相应趋近过程下的等价无穷小；有限阶 Taylor 展开必须保留余项意识，不能当作全局恒等式。
- 统计部分统一用左侧分位点 q_p：P(T≤q_p)=p。若教材采用“上 α 分位点”，需先换算，不能混用符号。
- 速查表只负责唤醒，不替代推导。每次错题至少记录：没想到、条件漏检、公式记错、代数执行错中的哪一类。

| F-P3-01 | 边缘密度 f_X(x)=∫f(x,y)dy；条件密度 f_{Y\|X}(y\|x)=f(x,y)/f_X(x) | 二维连续分布 | [背] | 积分限由支撑区域决定；分母需正 |
| F-P3-02 | 独立连续变量：f(x,y)=f_X(x)f_Y(y)，且支撑区域应为边缘支撑的直积 | 独立性 | [慎] | 公式局部可分解但支撑非直积时仍可能不独立 |
| F-P3-03 | Z=X+Y：f_Z(z)=∫f_X(x)f_Y(z-x)dx（独立） | 和的卷积 | [背] | 积分上下限由两个支撑集交集决定 |
| F-P3-04 | M=max(X_i)：F_M(x)=F(x)^n；m=min(X_i)：F_m(x)=1-[1-F(x)]^n | i.i.d. 最大/最小次序统计量 | [背] | 最小值常用补事件“全部>x” |
| F-P3-05 | 第 k 个次序统计量密度：n!/[ (k-1)!(n-k)! ]·F^{k-1}(1-F)^{n-k}f | i.i.d. 连续样本 | [背][慎] | k=1,n 应退化为最小/最大公式 |
| F-P3-06 | 二维变换 (U,V)=T(X,Y)：f_{U,V}=f_{X,Y}(x(u,v),y(u,v))·\|∂(x,y)/∂(u,v)\| | 一一可逆变换 | [背][慎] | 多对一分支相加；先画新旧支撑 |
| F-P4-01 | E[g(X)]=Σg(x)p(x) 或 ∫g(x)f(x)dx | 只求函数期望，无需先求分布 | [背] | 存在性需检查绝对可积/级数收敛 |
| F-P4-02 | D(X)=E(X²)-[EX]²；D(aX+b)=a²D(X) | 方差计算 | [背] | 平移不改变方差 |
| F-P4-03 | Cov(X,Y)=E(XY)-EX·EY；ρ=Cov/(σ_Xσ_Y) | 协方差与相关 | [背] | 相关系数要求两个标准差非零 |
| F-P4-04 | D(X+Y)=D(X)+D(Y)+2Cov(X,Y) | 线性组合 | [背] | 只有独立或不相关时交叉项为 0 |
| F-P4-05 | 独立且矩存在 ⇒ E(XY)=EX·EY ⇒ Cov=0 | 独立到不相关 | [背] | 逆命题一般不成立；联合正态是重要例外 |
| F-P4-06 | E[max(X,Y)]+E[min(X,Y)]=EX+EY | 最大最小的期望关系 | [推] | 由点态恒等式 max+min=X+Y，不需独立 |
| F-P5-01 | Chebyshev：P(\|X-EX\|≥ε)≤D(X)/ε² | 只知均值方差的概率界 | [背] | ε>0；通常只是上界而非精确概率 |
| F-P5-02 | i.i.d. 且 E\|X\|<∞：X̄_n→μ（依概率，Khintchine） | 大数定律 | [慎] | 结论是收敛，不给有限 n 的近似分布 |
| F-P5-03 | i.i.d.，EX=μ，DX=σ²∈(0,∞)：(ΣX_i-nμ)/(σ√n)⇒N(0,1) | Lindeberg-Levy 中心极限定理 | [背][慎] | 是分布收敛/近似，不是原和严格正态 |
