# 第三部分 概率论与数理统计（P）

概率部分的主线是：事件概率 → 随机变量分布 → 多维联合分布 → 数字特征 → 极限定理 → 样本统计量 → 参数估计与检验。每一步都建立在前一步的分布信息上。

## P1 随机事件与概率｜优先级 A+

**本章目标：** 熟练进行事件翻译和条件概率分解。

### 知识节点
- P1.1 样本空间、事件、互斥、对立、包含；事件运算与 De Morgan 律。
- P1.2 概率公理与基本性质；加法公式、容斥。
- P1.3 古典概率与几何概率；计数时区分有序/无序、放回/不放回。
- P1.4 条件概率与乘法公式。
- P1.5 全概率公式与 Bayes 公式。
- P1.6 独立性：两两独立、相互独立、条件独立的辨析。
- P1.7 Bernoulli 概型与重复独立试验。

### 核心方法
- 先把自然语言翻译成事件，再画树或按原因分组；条件概率题优先找分母对应的条件事件。
- 至少、至多、恰好等词先写集合表达式，避免计数时漏项。

### 典型题型
- 事件关系判断
- 条件概率
- 全概率/Bayes
- 独立性
- 重复试验

### 高频易错边界
- 互斥误当独立
- P(AB)=P(A)P(B) 只在独立时成立
- 条件概率分母写错
- 两两独立误推相互独立

### 达标标准
复杂文字题能先给事件命名，并用一张概率树或分割写出完整计算。

## P2 一维随机变量及其分布｜优先级 A+

**本章目标：** 从分布函数统一理解离散型与连续型。

### 知识节点
- P2.1 随机变量与分布函数 F(x)：单调、右连续、两端极限。
- P2.2 离散型：分布律、概率质量函数、归一化。
- P2.3 连续型：密度、分布函数、区间概率；点概率为零。
- P2.4 常见离散分布：0-1、二项、Poisson、几何、超几何。
- P2.5 常见连续分布：均匀、指数、正态；指数分布无记忆性。
- P2.6 随机变量函数的分布：分布函数法、单调变换公式、分段与多对一变换。
- P2.7 混合型或带原子分布的识别（作为拓展，防止被分布函数跳跃迷惑）。

### 核心方法
- 求 Y=g(X) 分布优先用 F_Y(y)=P(g(X)≤y)，单调且可逆时再用密度变换公式。
- 先确定 Y 的取值范围，再分区间；绝对值、平方、分段函数通常是多对一。

### 典型题型
- 由 F 求概率/密度
- 常见分布识别
- 参数归一化
- 变量函数分布

### 高频易错边界
- 连续型点概率不为零的误解
- 分布函数左连续误判
- 变换后漏分支或漏绝对值 Jacobian
- 正态标准化方向错误

### 达标标准
能从分布律、密度或 F(x) 互相转换，并能处理非单调变换。

## P3 多维随机变量及联合分布｜优先级 A+

**本章目标：** 掌握联合—边缘—条件—独立—函数分布的完整链条。

### 知识节点
- P3.1 二维联合分布函数及性质。
- P3.2 二维离散型联合分布表；边缘分布与条件分布。
- P3.3 二维连续型联合密度；积分区域与归一化。
- P3.4 边缘密度、条件密度。
- P3.5 随机变量独立的联合分布判据与支持域条件。
- P3.6 二维均匀分布与几何概率。
- P3.7 二维正态分布：参数、边缘、条件、独立与不相关关系。
- P3.8 随机变量函数分布：和、差、积、商、最大值、最小值。
- P3.9 卷积公式；Jacobian 变换法。

### 核心方法
- 连续型题先画联合密度支持域；边缘密度就是沿另一变量可行截面积分。
- 最大最小值优先用分布函数：P(max≤z)、P(min>z)；独立时可拆乘积。
- 二维变换先求反变换与 Jacobian，再确定新变量支持域；支持域往往比积分本身更难。

### 典型题型
- 联合/边缘/条件
- 独立性
- 二维区域概率
- 和与极值分布
- 变量变换

### 高频易错边界
- 密度可分解却忽略支持域非矩形
- 条件密度分母边缘密度为零处
- 卷积上下限不按支持域截取
- 二维正态不相关与独立的适用范围混淆

### 达标标准
能准确画支持域并写出边缘、条件和卷积积分上下限。

## P4 随机变量的数字特征｜优先级 A+

**本章目标：** 熟练使用期望、方差、协方差与相关系数进行降维计算。

### 知识节点
- P4.1 数学期望：定义、存在性、线性性质。
- P4.2 随机变量函数期望：LOTUS 公式；不必先求新分布。
- P4.3 方差与标准差：D(X)=E(X²)−[E(X)]²；平移缩放。
- P4.4 协方差、相关系数及性质。
- P4.5 和的方差；独立 ⇒ 不相关，但一般不相关不 ⇒ 独立。
- P4.6 常见分布的期望与方差。
- P4.7 协方差矩阵、线性组合的期望与方差。
- P4.8 条件分解思想（拓展）：通过分类计算期望和方差。

### 核心方法
- 求 E[g(X,Y)] 通常直接对联合分布求和/积分，不先求 g 的分布。
- 方差题先写线性组合公式，再判断协方差是否为零；不要凭‘看起来无关’判独立。

### 典型题型
- 期望方差计算
- 线性组合
- 协方差相关
- 由数字特征反推参数
- 最优化

### 高频易错边界
- E(XY)=EX·EY 无条件使用
- D(X+Y)=DX+DY 无条件使用
- 相关系数为零误判独立
- 期望存在性不检查

### 达标标准
能在分布计算与数字特征直接计算之间选更短路线。

## P5 大数定律与中心极限定理｜优先级 A

**本章目标：** 理解‘样本平均趋于常数’与‘标准化后近似正态’的区别。

### 知识节点
- P5.1 Markov 与 Chebyshev 不等式。
- P5.2 Bernoulli 大数定律。
- P5.3 Khintchine 大数定律。
- P5.4 de Moivre–Laplace 中心极限定理。
- P5.5 Lindeberg–Levy 中心极限定理。
- P5.6 标准化、连续性修正与近似概率计算。
- P5.7 大数定律与中心极限定理的适用目的、条件和结论比较。

### 核心方法
- 先判断题目是在问‘偏离均值概率上界’、‘频率稳定’还是‘大样本近似概率’。
- CLT 必须先求和的均值与方差，再标准化；二项近似正态注意连续性修正。

### 典型题型
- 不等式估计
- 频率概率
- 大样本和/均值近似
- 样本量反求

### 高频易错边界
- 把大数定律当成分布收敛到正态
- 标准化分母漏 √n
- 连续性修正方向错误

### 达标标准
能根据题目目标准确选择大数定律或 CLT，并完整写出标准化过程。

## P6 数理统计基本概念与抽样分布｜优先级 A+

**本章目标：** 掌握样本、统计量以及正态总体下三大抽样分布。

### 知识节点
- P6.1 总体、个体、简单随机样本、样本值、统计量。
- P6.2 样本均值、样本方差、样本矩与顺序统计量。
- P6.3 χ²、t、F 分布的定义、性质、分位点。
- P6.4 正态总体样本均值的分布。
- P6.5 (n−1)S²/σ² 的 χ² 分布。
- P6.6 正态总体下样本均值与样本方差独立。
- P6.7 单正态总体标准化统计量；两正态总体均值差与方差比。
- P6.8 Cochran/Fisher 结构的理解：平方和分解、自由度与独立性。

### 核心方法
- 抽样分布题先判断总体是否正态、σ²是否已知、是一总体还是两总体，再选 Z/t/χ²/F。
- 自由度来自独立标准正态平方和的项数或约束后的维数，不能死记分母。

### 典型题型
- 统计量分布
- 概率计算
- 分位点
- 自由度
- 独立性判断

### 高频易错边界
- 样本方差分母 n 与 n−1 混淆
- 非正态总体直接套精确 t/χ²/F
- t 统计量中 σ 与 S 混用
- F 分布分子分母自由度颠倒

### 达标标准
看到正态样本统计量能迅速识别标准化后的分布与自由度。

## P7 参数估计｜优先级 A+

**本章目标：** 掌握点估计构造、评价和区间估计的标准流程。

### 知识节点
- P7.1 点估计与估计量。
- P7.2 矩估计：总体矩 = 样本矩；多参数联立。
- P7.3 最大似然估计：似然函数、对数似然、边界最大值与离散参数。
- P7.4 估计量评价：无偏性、有效性、相合性。
- P7.5 置信区间、置信水平与枢轴量。
- P7.6 单正态总体均值区间：σ²已知/未知。
- P7.7 单正态总体方差区间。
- P7.8 两正态总体均值差、方差比的区间估计（按大纲要求掌握常见情形）。

### 核心方法
- MLE 先写参数空间；求驻点后还要比较边界，尤其均匀分布、离散分布。
- 区间估计从不含未知参数且分布已知的枢轴量出发，再解不等式。

### 典型题型
- 矩估计
- MLE
- 无偏/有效性
- 置信区间
- 样本量设计

### 高频易错边界
- 似然函数把样本当变量而非固定观测
- 对数似然漏参数范围
- 无偏估计与估计值混淆
- 置信区间概率解释错误

### 达标标准
能独立写出似然函数并处理边界；能从枢轴量推导区间而非只背模板。

## P8 假设检验｜优先级 A

**本章目标：** 理解检验逻辑，并与置信区间、两类错误对应起来。

### 知识节点
- P8.1 原假设、备择假设、简单/复合假设。
- P8.2 检验统计量、拒绝域、显著性水平、p 值。
- P8.3 第一类错误与第二类错误；样本量、显著性和功效的关系。
- P8.4 单正态总体均值检验：σ²已知/未知；双侧/单侧。
- P8.5 单正态总体方差检验。
- P8.6 两正态总体均值差与方差比检验的常见模型。
- P8.7 假设检验与置信区间的对偶关系。

### 核心方法
- 先写 H0/H1 的方向，再按总体模型选统计量，最后由 H1 方向决定单侧或双侧拒绝域。
- 拒绝 H0 只表示证据足够，不拒绝不等于证明 H0 为真。

### 典型题型
- 构造拒绝域
- 判断是否拒绝
- 显著性/错误概率
- 检验与区间互换

### 高频易错边界
- 单侧方向写反
- 临界值上下分位点混乱
- 把不拒绝说成接受为真
- 第一二类错误条件概率对象写反

### 达标标准
能从文字目标正确写 H0/H1，并解释拒绝结论的统计含义。

## P9 概率统计综合连接层｜优先级 A+

**本章目标：** 建立分布、数字特征、抽样分布和推断之间的信息流。

### 知识节点
- P9.1 条件概率/全概率 ⇔ 混合分布。
- P9.2 联合分布 ⇔ 边缘/条件 ⇔ 独立 ⇔ 数字特征。
- P9.3 随机变量变换 ⇔ Jacobian ⇔ 和/极值分布。
- P9.4 期望方差 ⇔ 大数定律/CLT。
- P9.5 正态样本 ⇔ χ²/t/F ⇔ 估计/检验。
- P9.6 顺序统计量 ⇔ 最大最小值分布。
- P9.7 参数问题：归一化参数、分布参数、估计参数的区分。

### 核心方法
- 综合题先画信息链：已知联合分布 → 求统计量分布 → 构造估计量 → 评价。
- 能直接算期望时不要先求分布；必须求分布时优先 CDF，再考虑卷积/Jacobian。

### 典型题型
- 联合分布综合
- 估计量性质证明
- 极值/次序统计量
- 正态总体综合

### 高频易错边界
- 把随机变量、样本、统计量、估计量层级混淆
- 同一个字母既当参数又当变量
- 条件独立与无条件独立混用

### 达标标准
能把一道概率综合题拆成若干明确的信息转换步骤，而不是边算边猜。
