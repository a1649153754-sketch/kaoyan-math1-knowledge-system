### 核心讲解1：事件代数先处理集合，再处理数值

**为什么成立**：事件是样本空间的子集，交表示同时发生，并表示至少一个发生，补表示不发生。概率公理把空集、全集和互斥可加性赋予这些集合；一般加法公式中的减交集，正是为了纠正重复计数。De Morgan 律把“至少一个”和“全部不”互换，常能把复杂概率转成更简单的补事件。

**怎么用**：先定义简短事件符号，用集合式表达题意，再代概率。出现“至少、至多、恰有、都不”时优先写补事件或按个数分层。计数前列四个选择：对象是否可区分、顺序是否重要、是否放回、基本结果是否等可能；只有最后一项成立才能直接用有利数除总数。

**小例题 / 路线演示**：两事件 A、B 中至少一个发生为 `A∪B`，概率 `P(A)+P(B)-P(AB)`；至少一个不发生是 `(AB)^c=A^c∪B^c`。若求三次独立试验至少一次成功，补事件“全失败”最短，结果为 `1-(1-p)^3`。

**哪里会失效**：把 `P(A∪B)` 直接写成两概率相加会重复计算交集；只有互斥时交集概率为零。几何概率若区域上的取点并非均匀，面积比也不再代表概率。样本空间改变时事件的补集随之改变，不能脱离全集谈补。

### 核心讲解2：条件概率、全概率和 Bayes 是同一棵分层树

**为什么成立**：条件概率 `P(A|B)=P(AB)/P(B)` 把样本空间缩到 B 内重新归一化。乘法公式沿树枝把连续条件相乘；完备事件组把所有原因分支合并，得到全概率；Bayes 再用联合概率除以结果总概率，把“原因到结果”的方向反转成“已知结果追原因”。

**怎么用**：画树时第一层写原因及先验概率，第二层写各原因下结果的条件概率。沿枝相乘得到联合概率，跨枝相加得到结果概率，最后目标枝除以结果总和得到后验概率。独立性则检查条件后概率是否不变，或交概率能否分解；三个以上事件要验证任意子组。

**小例题 / 路线演示**：两机器分别生产 60%、40% 的产品，次品率 1%、3%。随机产品为次品的概率是 `0.6·0.01+0.4·0.03=0.018`；已知次品来自第二台的概率为 `0.4·0.03/0.018=2/3`。分母必须包含所有可能来源。

**哪里会失效**：若 `P(B)=0`，普通条件概率没有定义。互斥的正概率事件不独立，因为交概率为零而概率乘积为正。三事件两两独立只检查了两两交，仍可能三者联合关系异常；经典两次抛硬币构造的“首正、次正、同面”就是反例。

### 章末路线选择

1. 先把文字翻译为事件集合和补事件。
2. 计数前核对等可能、有序性与是否放回。
3. 条件问题画概率树，沿枝乘、跨枝加、Bayes 再归一。
4. 独立性回到乘法定义，三个以上事件检查全部子组。

- 能区分互斥、对立与独立。
- 能从一棵概率树同时写出全概率和 Bayes。

- **温柔讲解**：学到 `P2.7` 时，如果“混合型或带原子分布的识别（作为拓展，防止被分布函数跳跃迷惑）”显得有点密，不用一次吞下所有结论。它在用分布完整描述一个随机变量里主要照看“混合型或带原子分布的识别（作为拓展，防止被分布函数跳跃迷惑）”。先轻轻问自己：“离散还是连续，分布函数、密度与取值范围是否一致？”再从“求概率优先从分布函数或支持集积分/求和；随机变量变换先用事件法找新分布函数，单调时再用反函数密度公式，多对一时分支相加”开始，一步一步写出可检查的中间量。若遇到“连续型点概率为零但密度可大于 1；分布函数不必处处可导，密度公式只适用于绝对连续部分，变换后必须重新确定支持集”这样的信号，就先停一下补条件，这不是退步，而是在保护后面的推理。最后试着不用公式表说清对象、条件和回验方法，这个点就已经被你稳稳接住啦。

### 核心讲解1：分布函数统一离散、连续与混合分布

**为什么成立**：`F(x)=P(X≤x)` 对任何随机变量都成立，因此它是最统一的描述。离散分布在原子点跳跃，跳跃大小就是点概率；绝对连续分布可写为密度积分，区间概率是曲线下面积；混合分布同时包含跳跃和连续增长。右连续来自事件集合随阈值从右侧递减到当前事件。

**怎么用**：拿到 F 先查四件事：单调、右连续、`F(-∞)=0`、`F(+∞)=1`。离散型从跳跃读概率，连续型在可导处求密度并检查支持集，混合型把跳跃质量与连续部分分别归一。算区间概率时统一用端点的左右极限处理开闭。

**小例题 / 路线演示**：若 `P(X=0)=1/3`，其余 `2/3` 在 `(0,1)` 上均匀，则 F 在 0 处从 0 跳到 1/3，随后在 `[0,1]` 线性增长到 1。这既不是纯离散也不是纯连续；点质量与密度积分相加才是总概率。

**哪里会失效**：密度值不是点概率，可以大于 1，例如 `U(0,1/2)` 的密度为 2；概率仍由面积给出。分布函数有跳跃时不能把导数当作完整分布，导数会漏掉原子质量。连续型的 `P(X=x)=0` 也不表示事件不可能，只表示单点概率为零。

### 核心讲解2：随机变量变换最稳的是先求事件原像

**为什么成立**：新变量 `Y=g(X)` 的分布由事件 `{g(X)≤y}` 在 X 空间中的原像决定。若 g 单调，这个原像是一个区间，求导便得到反函数密度公式；若 g 多对一，同一个 y 有多个原像分支，各分支的概率贡献必须相加。分布函数法不依赖单调，因此是通用底座。

**怎么用**：先画 X 的支持集和 g 的图像，确定 Y 的取值范围。写 `F_Y(y)=P(g(X)≤y)`，按 y 的临界值分段解不等式；可导后再求密度。单调一一时使用 `f_Y(y)=f_X(g^{-1}(y))|(g^{-1})′(y)|`，多对一则对全部合法原像求和。

**小例题 / 路线演示**：若 `X~U(-1,1)`，`Y=X²`，则 `0≤Y≤1`。对 `0≤y≤1`，`F_Y(y)=P(-√y≤X≤√y)=√y`，故 `f_Y(y)=1/(2√y)`。直接套单调公式会漏掉正负两个原像，分布函数法自然合并了它们。

**哪里会失效**：变换后若忘记支持集，密度公式可能在不可能区域给正值。指数分布无记忆性是特定分布性质，不能推广到任意连续寿命。正态标准化要求同步改变均值和标准差，方差缩放用系数平方，不能用绝对值或一次方。

### 章末路线选择

1. 先判离散、连续或混合并画支持集。
2. 用分布函数统一处理概率、跳跃和变换。
3. 常见分布先识别参数含义，再套概率与矩公式。
4. 变换先找原像和新支持，多对一分支全部相加。

### 核心讲解1：二维概率的难点首先是支持区域

**为什么成立**：联合密度给每个小面积单元分配概率强度，概率是区域上的二重积分。边缘分布把另一个变量的所有可能值累加掉，条件分布则在给定切片上重新归一。积分上下限并非公式附属物，而是支持区域的几何描述；同一个密度表达式放在三角形与矩形上，会产生完全不同的边缘和独立性。

**怎么用**：先画联合支持并标边界交点。求 `f_X(x)` 时固定 x，看竖线穿过的 y 范围；求条件密度再除以该边缘并注明分母正。离散表按行列求和。归一化参数先对整个支持区积分为 1，再进行后续计算。

**小例题 / 路线演示**：若联合密度在三角形 `0<y<x<1` 上为常数 c，面积为 1/2，所以 c=2。边缘 `f_X(x)=∫₀ˣ2dy=2x`；给定 X=x 时，Y 在 `(0,x)` 上均匀。所有上下限都由三角形切片得到。

**哪里会失效**：若只写 `f(x,y)=g(x)h(y)` 就判独立，会忽略支持集。上例常数 2 可形式分成常数乘常数，但三角形不是两个一维区间的直积，所以 X、Y 不独立。条件密度在边缘密度为零处没有定义，不能机械作比。

### 核心讲解2：独立性是联合结构分解，不相关只是二阶矩为零

**为什么成立**：独立要求任意事件概率乘法分解，对连续变量等价为联合分布与边缘乘积在支持上匹配。这会推出可积函数乘积期望分解，进而协方差为零；反向一般不成立，因为协方差只观察线性二阶关系。联合正态是重要例外，其结构完全由均值和协方差控制，零协方差才足以推出独立。

**怎么用**：判断独立先比较支持域是否为边缘支持直积，再验证联合分布或密度乘积。只需否定时，找一个矩形事件不满足乘法即可。二维正态先确认“联合正态”而非仅两个边缘都正态，再由相关系数判断独立。

**小例题 / 路线演示**：令 X 在 `{-1,0,1}` 上对称，Y=X²。由于 `E[X³]=0`，常可得 `Cov(X,Y)=0`，但 Y 完全由 X 决定，显然不独立。这个反例说明相关系数只检测线性联系，无法看见平方关系。

**哪里会失效**：两个边缘变量分别正态不保证它们联合正态，因此也不能仅凭不相关判独立。联合密度乘积判据必须连同支持域和几乎处处意义。独立变量函数在各自单独作用后仍独立，但若两个新变量共享原变量，不能套这条性质。

### 核心讲解3：和、极值与一般二维变换都从原像累加

**为什么成立**：求 `Z=X+Y` 时，事件在联合平面上对应斜线切片，独立情形沿 `x+y=z` 累加得到卷积。最大值不超过 z 等价于每个变量都不超过 z，最小值大于 z 等价于每个变量都大于 z。一般可逆变换用 Jacobian 修正局部面积；多对一时每个原像分支都贡献概率。

**怎么用**：和差问题先画两个支持区间在 `x+y=z` 下的交集，写卷积积分限；最大最小优先求分布函数并用独立乘法。二维变换先求逆、画新支持、计算 `|∂(x,y)/∂(u,v)|`，确认一一；若非一一则分区域或枚举分支。

**小例题 / 路线演示**：独立 `X,Y~U(0,1)`，`Z=X+Y`。当 `0<z<1`，x 从 0 到 z，密度为 z；当 `1≤z<2`，x 从 z-1 到 1，密度为 `2-z`。三角形密度形状来自斜线与单位正方形交段长度，而不是背出的分段。

**哪里会失效**：卷积积分从负无穷到无穷只是形式，实际必须限制两个密度同时非零。极值公式 `F_M=F^n` 要求独立同分布。Jacobian 应取逆变换的绝对行列式或正确换算，使用正向行列式却不取倒数会系统性错误。

### 章末路线选择

2. 边缘靠积分消元，条件靠重新归一，独立同时检查公式和支持。
3. 和、差、积、商、极值先用事件原像理解。
4. 一般变换写逆映射、Jacobian、新支持和全部分支。

### 核心讲解1：期望是按概率加权的平均，不必先求新分布

**为什么成立**：期望把每个可能取值按其概率权重累加，是随机变量的重心。LOTUS 说明 `E[g(X)]` 可直接在 X 的原分布上计算 `Σg(x)p(x)` 或 `∫g(x)f(x)dx`，因为每个原像的概率已经由原分布记录。期望线性来自求和积分线性，与变量是否独立无关。

**怎么用**：先查绝对可积或相应级数收敛，再直接代入目标函数。求最大最小等复杂函数期望时，可以用点态恒等式、尾积分或条件分解，未必要先推完整分布。常见分布的矩可作为复核，但参数化版本要核对本仓库约定。

**小例题 / 路线演示**：若 X 的期望和方差已知，求 `E[(X-a)²]` 不必知道平方变量分布：展开得 `E[X²]-2aE[X]+a²=D(X)+(EX-a)²`。这也说明在均方意义下选择 `a=EX` 最优。

**哪里会失效**：期望可能不存在或正负部分分别发散，此时不能用形式相消得到数值。`E[g(X)]` 公式需要可积条件。把 `E[XY]=EX·EY` 当成无条件线性性质是错误的，它通常来自独立，而 `E[X+Y]` 才无需独立。

### 核心讲解2：方差与协方差记录波动和共同变化

**为什么成立**：方差是到均值平方距离的期望，展开得 `D(X)=E(X²)-(EX)²`。平移不改变离均值的距离，缩放 a 会使平方距离乘 `a²`。协方差是中心化乘积的期望，描述线性同向变化；线性组合方差展开后，每对变量都产生协方差交叉项。

**怎么用**：方差计算优先二阶矩公式；和的方差写全 `D(X+Y)=DX+DY+2Cov(X,Y)`，确认独立或不相关后才能删交叉项。相关系数再除标准差得到无量纲量，并检查方差非零。多变量用协方差矩阵 `Σ`，线性组合方差为 `aᵀΣa`。

**小例题 / 路线演示**：若 `D(X)=1,D(Y)=4,Cov(X,Y)=-1`，则 `D(X+Y)=1+4-2=3`。若直接相加得到 5，就忽略了负相关带来的抵消。对 `2X-Y`，按系数平方和交叉项可写 `4DX+DY-4Cov(X,Y)`。

**哪里会失效**：独立推出协方差为零需要相关矩存在，反向一般不成立。相关系数只能在两个标准差非零时定义，常数变量没有相关系数。方差永不为负，算出负数通常暴露二阶矩、均值平方或协方差系数错误。

### 核心讲解3：条件分解把复杂随机性拆成组内与组间

**为什么成立**：条件期望先在给定信息下平均，再对条件变量平均，得到全期望 `E[X]=E(E[X|Y])`。总方差分解 `D(X)=E[D(X|Y)]+D(E[X|Y])` 把总波动分成组内随机波动与不同组均值之间的波动。它是全概率思想在数字特征上的对应。

**怎么用**：当随机过程先抽类别再生成数值时，优先以类别为条件。先算每类条件均值、条件方差，再按类别概率加权；总方差不要只平均条件方差，还要加条件均值的方差。混合分布、随机和和两阶段试验都适合这条路线。

**小例题 / 路线演示**：机器类别 C 以相等概率选择，两类产品重量均值分别 0、2，类内方差都为 1。总均值为 1；平均类内方差为 1，条件均值的方差也为 1，所以总方差为 2。只平均类内方差会漏掉两类中心不同造成的波动。

**哪里会失效**：`E[D(X|Y)]` 不等于总方差，除非条件均值几乎不变。条件期望本身是 Y 的函数，不是固定常数。使用条件分解时条件事件概率为零处无需单独定义，但最终表达要在几乎处处意义下成立。

### 章末路线选择

1. 先检查矩存在性，函数期望优先 LOTUS。
2. 方差转二阶矩，线性组合写全协方差项。
3. 独立与不相关分开判断，联合正态例外单列。
4. 两阶段或混合模型使用全期望与总方差分解。

### 达标标准

- 能不求新分布直接计算函数期望。
- 能正确展开任意线性组合方差。
- 能解释独立与不相关的逻辑方向。
- 能用条件分解区分组内和组间波动。

### 核心讲解1：大数定律解释平均为何稳定，概率不等式提供控制

**为什么成立**：Markov 不等式把非负随机变量的大取值概率用其均值控制，Chebyshev 将它用于平方偏差，得到偏离均值概率不超过方差与阈值平方之比。对独立同分布且矩条件满足的样本均值，方差随 n 按 `1/n` 缩小，Chebyshev 因而推出样本均值依概率靠近总体均值，这就是大数定律的基本机制。

**怎么用**：只知非负量均值时先 Markov，只知均值方差时中心化后用 Chebyshev。重复试验频率题把样本均值识别为 0-1 变量平均。写大数定律时明确收敛方式和矩条件；有限 n 的误差概率可用不等式给保守上界，但不要把上界当精确概率。

**小例题 / 路线演示**：若 `X_i` 独立同分布、均值 μ、方差 σ²，则 `D(X̄)=σ²/n`，Chebyshev 给 `P(|X̄-μ|≥ε)≤σ²/(nε²)`，随 n 增大趋零。因此 X̄ 依概率收敛到 μ。这个推导直接展示了独立使方差相加、平均使尺度平方缩小。

**哪里会失效**：Chebyshev 给的通常只是粗上界，不能据此算等号概率。若样本存在强相关，方差未必按 `1/n` 缩小；若均值不存在，经典 Khintchine 大数定律不适用。大数定律描述平均的稳定，不提供钟形近似。

### 核心讲解2：中心极限定理描述标准化总和的形状

**为什么成立**：大量独立同分布变量相加时，总均值按 n 增长、总方差按 n 增长。减去 `nμ` 再除以 `σ√n` 后，位置与尺度被标准化；在有限正方差等条件下，其分布趋向标准正态。大数定律回答平均靠近哪里，中心极限定理回答偏差在 `1/√n` 尺度上呈什么形状。

**怎么用**：先把目标写成和或样本均值，计算准确均值和标准差，再标准化到 Z。二项分布近似正态时按题目要求使用连续性修正，例如 `P(S≤k)` 用边界 `k+0.5`；最后查标准正态分布。若原总体正态，样本均值有限 n 已精确正态，不必称为 CLT 近似。

**小例题 / 路线演示**：`S~B(n,p)` 时均值 `np`、方差 `np(1-p)`。当 n 足够大且 p 不极端，`P(S≤k)` 近似为 `Φ((k+0.5-np)/√(np(1-p)))`。`+0.5` 把离散柱形的右边界与连续面积对齐。

**哪里会失效**：CLT 是分布收敛，不是说每个有限 n 的和严格正态；小样本或重尾分布可能近似很差。标准化分母是总和标准差 `σ√n`，不是 `nσ`。连续性修正只用于离散到连续近似，原本连续的样本均值不加。

### 章末路线选择

1. 只知矩求概率界，先看 Markov 或 Chebyshev。
2. 研究样本平均稳定性使用大数定律并写收敛方式。
3. 研究标准化总和形状使用 CLT，准确计算中心和尺度。
4. 离散正态近似按要求使用连续性修正并检查样本条件。

- **温柔讲解**：可以把 `P6.8` 的“Cochran/Fisher 结构的理解”想成从总体走向样本统计量的随机分布中的一把小钥匙：它不是要求你背一串名词，而是帮你处理“平方和分解、自由度与独立性”。做题时别急着展开，先问“统计量由哪些独立样本构成，它服从哪一种枢轴分布？”，确认后按“把统计量标准化为正态、平方和或方差比结构，写清自由度；两样本问题先判独立、方差已知/未知和是否假设等方差”推进。如果题目碰到“样本值是观测结果，统计量在抽样前仍是随机变量；样本均值与样本方差独立是正态总体的特殊性质，自由度和分位点顺序不能互换”，就回到定义或分情形检查；能主动停在边界前，比算得很快更可靠。你只要把第一步和停止条件讲清楚，后面的计算通常会温顺很多。

### 核心讲解1：统计量是样本的函数，抽样分布描述重复抽样

**为什么成立**：总体参数固定但未知，样本在抽取前随机，任何不含未知参数的样本函数称统计量。样本均值汇总位置，样本方差汇总围绕样本均值的波动；分母 n-1 来自估计均值后损失一个自由度，并使其对总体方差无偏。抽样分布描述若反复抽样，统计量会怎样变化。

**怎么用**：第一步区分总体分布、样本联合分布、统计量与一次样本值。计算样本均值方差时固定本仓库 `S²=Σ(X_i-X̄)²/(n-1)` 约定。顺序统计量先把样本排序，再用“有多少个落在阈值左侧”的二项事件推导分布。

**小例题 / 路线演示**：若 `X_i` 独立且均值 μ、方差 σ²，则 `E(X̄)=μ,D(X̄)=σ²/n`。若总体正态，线性组合性质进一步给 `X̄~N(μ,σ²/n)`，这是有限样本精确结论；非正态总体通常只有均值方差公式和大样本近似。

**哪里会失效**：把一次算出的 `x̄` 当随机变量、或把抽样前的 `X̄` 当固定数，会混淆推断对象。用分母 n 的样本方差对 σ² 有偏，不能与 n-1 版本的 χ² 公式混用。简单随机样本包含独立同分布条件，不能只写“来自同一总体”。

### 核心讲解2：χ²、t、F 来自正态平方和与独立比值

**为什么成立**：独立标准正态平方和服从 χ²，自由度等于独立平方项数。正态样本中，总离差平方和分成围绕总体均值与围绕样本均值的部分，估计均值消耗一维，故 `(n-1)S²/σ²~χ²(n-1)`；标准正态除以独立 χ² 均方根得到 t，两个独立 χ² 除自由度后的比得到 F。

**怎么用**：看到均值且 σ 未知，寻找 t 结构；看到单总体方差用 χ²；两个独立方差比用 F。每次都写分子分母来源、独立性和自由度。分位点采用左侧定义时，倒数会交换 F 的自由度和上下分位方向。

**小例题 / 路线演示**：正态样本中 `Z=(X̄-μ)/(σ/√n)~N(0,1)`，且 `U=(n-1)S²/σ²~χ²(n-1)` 与 Z 独立，所以 `Z/√(U/(n-1))=(X̄-μ)/(S/√n)~t(n-1)`。t 统计量不是把 σ 随便换成 S，而是依赖这一独立比值构造。

**哪里会失效**：非正态总体下 `X̄` 与 `S²` 一般不独立，t/χ²/F 精确结论不能机械套。自由度是结构中的独立信息数，不是总把 n 写成 n-1。F 分布不对称，分子分母交换后必须交换自由度并取倒数。

### 核心讲解3：两正态总体先判模型，再选枢轴量

**为什么成立**：两样本推断的统计量取决于样本是否独立、方差是否已知以及未知方差是否可视为相等。已知方差时均值差由正态线性组合标准化；未知但相等时可合并两个独立平方和估计共同方差，得到 pooled t；方差比则由两个独立 χ² 比形成 F。

**怎么用**：先列模型表：独立性、正态性、σ 已知/未知、等方差条件。均值差的中心要减题设假设值，标准误按模型计算；合并方差使用自由度加权。方差比固定分子分母顺序，并让自由度与对应样本一致。

**小例题 / 路线演示**：两个独立正态样本且方差未知但相等时，`S_p²=[(n₁-1)S₁²+(n₂-1)S₂²]/(n₁+n₂-2)`，均值差除以 `S_p√(1/n₁+1/n₂)` 后服从自由度 `n₁+n₂-2` 的 t。权重来自各平方和自由度。

**哪里会失效**：题目没有等方差条件时不能机械使用 pooled t。配对样本不是两个独立样本，应先对每对作差化成单样本问题。方差比若临时交换次序，拒绝域和置信区间分位点也必须全部同步。

### 章末路线选择

1. 先区分总体参数、随机样本、统计量与样本值。
2. 写明正态性、独立性、方差信息和样本方差约定。
3. 均值、方差、方差比分别匹配正态/t、χ²、F 结构。
4. 每个枢轴量标出中心、尺度、独立来源和自由度。

### 达标标准

- 能解释 n-1 自由度与无偏样本方差。
- 能从正态与 χ² 独立结构推导 t 统计量。
- 能按模型选择两样本均值差与方差比统计量。
- 能保持 F 分子分母和自由度顺序一致。

### 核心讲解1：矩估计与最大似然分别匹配总体特征和样本证据

**为什么成立**：矩估计用大数定律直觉，把总体矩方程换成样本矩后解参数；最大似然把观测样本在不同参数下出现的联合概率视为参数函数，选择使当前数据最可能的值。独立样本使似然成为单点密度乘积，对数把乘积化为和，但支持集中的参数限制仍属于似然的一部分。

**怎么用**：矩估计按参数个数选择相同数量的低阶矩，解后检查参数空间。MLE 先写完整似然含支持条件，再取对数、求内部驻点，同时检查边界、不可导点和离散候选。若密度支持上界含 θ，样本最大值常直接限制 θ，不能只对对数似然求导。

**小例题 / 路线演示**：样本来自 `U(0,θ)`。似然为 `θ^{-n}` 乘条件 `θ≥X_(n)`，在可行域随 θ 递减，所以最大值在边界 `θ̂=X_(n)`，而不是某个导数为零的内部点。矩估计由 `EX=θ/2` 得 `2X̄`，两种估计利用的信息不同。

**哪里会失效**：忽略支持条件会把 `θ^{-n}` 错误地推向 θ→0，而小于样本最大值的 θ 实际似然为零。对数似然只在似然正时等价。MLE 的不变性不能被误解为无偏性，非线性变换后的估计通常会有偏。

### 核心讲解2：估计量评价要分偏差、波动和大样本稳定

**为什么成立**：无偏性比较重复抽样平均是否等于参数；有效性通常在无偏估计量间比较方差；均方误差 `MSE=Var+Bias²` 同时衡量波动与系统偏差；相合性描述样本量增大时估计量依概率靠近参数。四者回答不同问题，不存在“无偏所以一切最好”的逻辑。

**怎么用**：先求期望得到偏差，再求方差并组合 MSE。比较估计量时先确认评价标准相同；证明相合可用期望趋参数、方差趋零配合 Chebyshev，或使用大数定律与连续映射。若估计量含未知参数，风险比较要说明对哪些参数成立。

**小例题 / 路线演示**：用分母 n 的样本方差 `S_n²` 有期望 `(n-1)σ²/n`，有限样本有偏，但偏差随 n 消失，且在常见条件下仍相合。分母 n-1 的 S² 无偏。这个例子直接说明无偏性与相合性互不等价。

**哪里会失效**：只比较方差而忽略偏差，可能偏爱严重偏置的估计量；只写期望等于参数也不能说明大样本集中。相合是参数固定时随 n 的极限性质，不是一次样本估得接近的保证。所谓有效性若未限定在同一无偏类中，表述会含糊。

### 核心讲解3：置信区间来自概率固定的枢轴量反解

**为什么成立**：枢轴量由样本和参数构成，但其分布不含未知参数。选择中间概率 `1-α` 的分位区间后，把不等式代数反解为参数落在随机上下限之间，就得到置信区间。随机性在区间构造规则和样本上，参数在频率学派中固定；置信水平是重复使用该规则的长期覆盖率。

**怎么用**：先按模型选 Z、t、χ² 或 F 枢轴量，写 `P(q_low≤T≤q_high)=1-α`，再保持不等号方向反解参数。遇参数在分母或平方项时特别注意倒数会交换端点。最后检查自由度、单双侧、单位和区间是否落在参数空间。

**小例题 / 路线演示**：正态总体 σ 未知时，`T=(X̄-μ)/(S/√n)~t(n-1)`。由对称分位点得到 `P(-t_{1-α/2}≤T≤t_{1-α/2})=1-α`，反解为 `X̄±t_{1-α/2}S/√n`。每个条件都来自枢轴结构。

**哪里会失效**：不能说本次已经算出的固定区间有 95% 概率包含固定参数；正确说法是构造方法长期覆盖率 95%。χ² 方差区间取倒数时端点顺序会反转。σ 已知与未知使用不同枢轴量，不能只因样本大就默认替换。

### 章末路线选择

1. 先写参数空间和完整样本似然，包括支持条件。
2. 矩估计解矩方程，MLE 同时查驻点、边界和离散候选。
3. 评价估计量分开计算偏差、方差、MSE 与相合性。
4. 置信区间从无参数分布的枢轴量反解，并核对分位点方向。

### 核心讲解1：假设检验控制的是错误决策概率

**为什么成立**：检验先把 H0 当作基准，选择一个在 H0 成立时分布已知的统计量。拒绝域被设计成 H0 为真时落入其中的概率不超过 α，这就是第一类错误控制。备择假设决定极端方向：双侧看两端，右侧或左侧检验只看相应一端。第二类错误和功效还依赖具体备择参数、样本量与效应大小。

**怎么用**：先用文字写清参数与方向，再选统计量。由 α 分配尾部得到临界值，代样本作决定；p 值法则计算在 H0 下观察到当前或更极端统计量的概率，与 α 比较。结论使用“拒绝”或“不拒绝”，并回到题目语境说明证据。

**小例题 / 路线演示**：检验正态总体均值 `H0:μ=μ₀` 对 `H1:μ>μ₀`，σ 已知时用 `Z=(X̄-μ₀)/(σ/√n)`，右尾拒绝域 `Z>z_{1-α}`。若观测 Z=2.1、α=0.05，因超过约 1.645 而拒绝 H0；同样可报告右尾 p 值。

**哪里会失效**：双侧检验不能因为样本差值为正就临时改成单侧，否则第一类错误控制被破坏。p 值小表示数据与 H0 不相容，不是 `P(H0|data)`。不拒绝可能来自 H0 近真，也可能来自样本小、噪声大和功效低。

### 核心讲解2：正态总体检验与置信区间来自同一枢轴结构

**为什么成立**：对标准正则模型，双侧 `1-α` 置信区间包含所有在水平 α 下不会被双侧检验拒绝的参数值。两者都从同一个 Z、t、χ² 或 F 枢轴量及其分位点构造，只是一个固定候选参数判断样本是否极端，另一个反解所有不被拒绝的参数集合。

**怎么用**：先根据 σ 已知/未知选择 Z 或 t，方差问题用 χ²，两方差比用 F。双侧检验分配 α/2 到两端，单侧只放一端；统计量中心必须减去 H0 中的假设值。完成后用对应置信区间检查：候选值在双侧区间外应与拒绝结论一致。

**小例题 / 路线演示**：若正态总体 σ 未知，双侧检验 `H0:μ=μ₀` 使用 `T=(X̄-μ₀)/(S/√n)`。同样本的 `1-α` t 区间若不包含 μ₀，等价于 `|T|>t_{1-α/2,n-1}`，于是拒绝 H0。这个对偶可发现分位点、自由度或单双侧写错。

**哪里会失效**：单侧检验对应单侧区间，不能拿双侧区间机械核对。方差 χ² 分布不对称，两端临界值不能写成正负同一数。两样本模型若不独立或不满足等方差，选择错误统计量会使名义 α 不再受控。

### 章末路线选择

1. 先由问题固定 H0、H1 和单双侧，不能看样本后改方向。
2. 按正态性、独立性与方差信息选择统计量及自由度。
3. 写拒绝域或 p 值规则，再代样本并用统计语言作结论。
4. 双侧检验用对应置信区间做对偶复核。

### 核心讲解1：概率模型从事件到推断是一条逐层压缩的信息链

**为什么成立**：事件概率描述不确定结果，随机变量把结果编码成数值，分布描述全部概率结构，期望方差压缩为低阶特征，大数与中心极限定理说明重复样本的稳定与近似，抽样分布最终把统计量与未知参数连接起来。估计和检验不是另起炉灶，而是在既定概率模型上反向推断参数。

**怎么用**：综合题先画层级：样本来自什么总体，目标是概率、分布、数字特征还是参数。能直接用 LOTUS 就不先求变换分布；需要统计推断时先确定抽样分布和枢轴量。每次从联合到边缘、从总体到样本，都写出被积分掉或被条件化的信息。

**小例题 / 路线演示**：若 `X_i~N(μ,σ²)`，分布层给出样本独立正态；数字特征层给 `E(X̄)=μ,D(X̄)=σ²/n`；抽样分布层给 σ 已知时 Z、未知时 t；推断层由相同枢轴量产生区间和检验。每一步都建立在前一步条件上。

**哪里会失效**：若总体非正态，小样本 t 与 χ² 精确结构可能失效；若样本不独立，均值方差和 CLT 形式会改变。综合题不能只看到最终公式相似就跳过模型层。把条件概率分母、密度支持或自由度漏掉，往往会在后续每层持续放大。

### 核心讲解2：参数、变换和顺序统计量要先辨对象角色

**为什么成立**：归一化常数使密度积分为 1，分布参数控制概率模型形状，估计参数是从样本反推的未知常数；三者可能使用相同字母却处在不同逻辑层。顺序统计量又是样本的函数，其分布来自“阈值左侧有多少样本点”的事件计数，与单个总体变量分布不同。

**怎么用**：先在符号旁标注“已知常数、总体参数、样本统计量或观测值”。含参密度先归一化并确定参数空间，再求概率或矩；估计时重新写似然。最大最小值分布优先事件法，i.i.d. 时 `F_max=F^n`、`F_min=1-(1-F)^n`，一般第 k 个顺序统计量用二项计数。

**小例题 / 路线演示**：样本来自 `U(0,θ)` 时，θ 是总体上界参数，`X_(n)` 是随机统计量，观测到的 `x_(n)` 才是数值。似然要求 `θ≥x_(n)`，MLE 为 `x_(n)`；推导其偏差则要回到随机变量 `X_(n)` 的分布。三种层级不能混写。

**哪里会失效**：将观测最大值直接写进抽样分布会失去随机性；把归一化求出的参数当估计结果，也混淆了题设角色。最大最小公式要求独立同分布，非独立样本不能把联合事件概率分解成幂。参数空间边界还会决定 MLE 是否存在或是否取到。

### 章末路线选择

1. 给每个符号标注总体参数、统计量或观测值角色。
2. 先完成支持集与归一化，再做边缘、变换和数字特征。
3. 从模型条件推抽样分布，再选择估计或检验枢轴量。
4. 跨层结论逐项复核独立、正态、矩存在与大样本条件。
